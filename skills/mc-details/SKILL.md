# A. 做旧与细节

# 做旧与细节手册(风化 / 损伤 / 叙事)

做旧不是把方块随机换色，而是让表面留下**环境、时间和使用者的证据**。
每次先问四件事：**这是什么建筑？暴露在哪？谁在用？发生了什么？** 四个答案决定风化方向。

## 0. 四层做旧法

1. **结构层**：先保证承重线完整。柱、梁、拱、屋顶可以破损，但不能全部断掉。
2. **表面层**：按暴露位置换材质，控制杂色、裂纹、苔藓、铜绿。
3. **损伤层**：开洞、缺块、塌角、断梁、碎裂瓦片；损伤必须集中在受力点/雨水线/人流线。
4. **叙事层**：补丁、脚手架、杂物、旧灯、堆货、断枝、洪水线，让玩家读出时间。

> 顺序固定：`结构 → 表面风化 → 损伤 → 修补痕迹 → 道具与植被`。先做道具会在大改时全部返工。

## 1. 风化预算(防花防脏)

- 普通使用中的建筑：风化材质 10%~20%，只做基座、檐口、背阴面和交通线。
- 老旧建筑：20%~35%，增加裂纹、缺块和修补痕迹。
- 废墟：35%~60%，保留 1~2 条清晰结构主线；不是全图噪声。
- 单一变体 `cracked_*` / `mossy_*` 占同族材质 ≤20%。
- 任意 10×10 区域内，藤蔓/苔藓/断枝等特殊细节 ≤15%。
- 藤蔓 1 处/3~5 格墙长，垂 2~4 格；苔藓成 3~7 格团，禁止单格孤立点。
- 生活道具密度：每 5×5 功能区 1~2 件小物；门口/桌面/墙角优先。
- 小建筑总细节上限：每 10 格立面不超过 3 个视觉焦点。

## 2. 材质风化配方

| 材质族 | 少量风化 | 中度风化 | 重度/废墟 |
|---|---|---|---|
| 石砌 | `stonebrick` + `stonebrick["stone_brick_type"="cracked"]` | `cobblestone` + `mossy_cobblestone` + `andesite` | `deepslate` + `cobbled_deepslate` + `gravel` |
| 砖墙 | `brick_block` + `granite` | `brick_block` + `stonebrick["stone_brick_type"="cracked"]` | `deepslate_bricks` + `tuff_bricks` + `mossy_cobblestone` |
| 木材 | `<木>_planks` + `stripped_log` | `<木>_planks` + `trapdoor` + `fence` | `dark_oak_planks` + `air` 缺口 + `dirt["dirt_type"="coarse"]` |
| 屋顶 | 主瓦 + 10% 深色变体 | `mossy_cobblestone` + `vine` + 缺瓦 | 露梁 + `moss_block` + 落叶 + 破口 |
| 铜/金属 | 原铜 + 1 阶氧化 | 2~3 阶氧化 + `copper_grate` | 全氧化 + 铁栏杆 + 锈水痕 |
| 沙岩/土坯 | `sandstone` + `sandstone["sand_stone_type"="cut"]` | `sandstone` 缺角 + `sand` 堆 | `terracotta` + `granite` + 裂口 |
| 柔软物 | 地毯磨损角 | 多色旧地毯 + 补丁 | 破布感 `white_wool` + `carpet` 拼块 |

- 石系渐变链：`stone → andesite → tuff → cobblestone → mossy_cobblestone → stonebrick → stonebrick["stone_brick_type"="cracked"] → deepslate → cobbled_deepslate → blackstone`。
- 暖木链：`oak_planks → spruce_planks → stripped_spruce_log → dark_oak_planks → dark_oak_log`。
- 铜绿链：`copper_block → exposed_copper → weathered_copper → oxidized_copper`；同一面墙按 2~3 段混，不是整面一次氧化。
- 湿区优先用 `moss_block`、`moss_carpet`、`vine`、`clay`；干区用 `dirt["dirt_type"="coarse"]`、`gravel`、`cracked_*`。

## 3. 损伤语法

- **雨水线**：墙脚 1~2 层更深更糙；檐口下方、窗台下方、门洞两侧加污渍/裂纹。
- **受力损伤**：裂纹从门洞上角、梁端、拱脚、墙角开始，不要凭空出现在大墙中央。
- **结构暴露**：先移除屋瓦/外墙 1~3 格，再补露出的梁、椽、柱；露结构必须有连续性。
- **塌角**：选择一角/一侧，从顶部向下 2~5 格逐层退，底部堆 rubble；不要四面同时塌。
- **缺窗**：玻璃留 1~2 格缺口，边缘用 `iron_bars`/`trapdoor`/木条；破口周围加少量碎石。
- **火烧**：近火源换 `cracked_deepslate_bricks`/`blackstone`/`deepslate_tiles`，上方加 `campfire` 烟痕；木质保留焦黑边缘。
- **洪水/潮湿**：水线以下石头加深、苔藓加密，木结构改 `dark_oak`/mud；水生植物只放水边。
- 先保留结构线，再破坏 1~2 个局部。**空、断、塌三选一，不要同时全塞。**

## 4. 修补与时间痕迹

- 补墙用不同批次材料：新 `stonebrick` 补旧 `cobblestone`，接缝留 1 格 `cracked_*`。
- 门洞用横木板/木板条封 1~3 格；旁边放 `ladder`、`scaffolding`、`fence` 做施工痕迹。
- 屋顶补瓦用不同深浅；补丁占屋面 5%~15%，不要补成棋盘。
- 修复柱外包一圈 `log`/`stonebrick`，保留内部破损；新旧材质差异就是故事。
- 道路车辙/门槛磨痕沿人流线：每 10~15 格一处 `dirt["dirt_type"="coarse"]`/`gravel`/深色 path。
- 废墟中保留 1 条清晰可读的旧路/墙基，玩家才能看出原来是什么。

## 5. 细节与生活道具

- 生命感来自"刚被使用过"：半开的门、亮着的灯、桌上食物、炉中火、晾衣、堆货、脚印旁的工具。
- 功能细节：灯、招牌、栅栏、楼梯、排水沟、烟囱、储物、工作台、座椅、花盆。
- 故事细节：破车、断桥、遗弃营火、散落书页、捆绑原木、集市摊、祭坛、墓碑、警告牌。
- 用组合而不是单块：`barrel + trapdoor + lantern` 是柜台，`fence + pressure_plate` 是小桌，`log + rail` 是货物，`lectern + trapdoor` 是摊开的书。
- 门口/窗边/转角优先；大墙中央只放一个焦点，不要满墙挂件。

详细材质、损伤与修补配方见 **`references/aging.md`**；道具清单、密度和场景故事模板见 **`references/details.md`**。

## 6. 落地流程

0. **园林构筑直接调函数**(`api.lib`, 见 **`references/functions-garden.md`**)):
   水池 `water_basin`/`round_basin`、跌水 `cascade`、九曲桥 `zigzag_bridge`、石舫 `stone_boat`、
   太湖石 `rockery`(内部真镂空)、游廊 `covered_walkway`、花池 `flower_bed`、花架 `arbor`。
   手搓假山必成“方块球”, 手搓跌水必成“水柱”——这两个是固定失败模式。
1. `get_slice` 读原结构与材质、`get_heightmap` 看地坪高差；`get_player_position` 定观察方向，先远看轮廓。
2. 用 `find_items` 找同族旧化方块，先做 3×3 小样确认颜色层级。
3. `pin_region` 覆盖施工面；表面换色用 `fill ... replace`，局部损伤用 `setblock`。
4. 大面积杂色/补丁/碎石用 `ptc` 批量提交 `run_server_command`；保存原结构线，不要用一次 `fill` 全墙换色。
5. 先做损伤，再加修补，再放道具，最后补藤蔓/苔藓/灯。
6. `inspect_region` 抽检：结构线连续、无单格苔藓、无悬空藤蔓、无堵路、无过度杂色。

## 7. 坑清单

- 随机满墙杂色 → 像噪点，不像风化；只沿暴露/受力/人流线分布。
- 苔藓单格孤立、藤蔓整墙满铺 → 成团、成簇、限高。
- 结构全断还叫废墟 → 先保留 1~2 条承重主线。
- 新旧材质无过渡 → 接缝留 10%~20% 中间色或裂纹。
- 只做损坏不做修补 → 缺少时间故事；补丁和脚手架很重要。
- 生活道具堆成仓库 → 每个功能区 1~2 件，围绕真实用途摆放。
- 室内照搬室外做旧 → 室内重磨损、烟熏、旧布和收纳，少用大型塌方。
- 忘 `pin_region`、ID 凭记忆猜 → 区块卸载会失败，Bedrock ID 以 `find_items`/`get_block` 为准。

# 绿化与景观手册(室内 / 园林 / 城市)

绿化不是"把草和树叶铺满"，而是用 **空间骨架 + 层次 + 焦点 + 动线** 组织植物。
地形改造见 `mc-terrain`，建筑结构见 `mc-architecture`，做旧见 `mc-details`，曲线水岸见 `mc-build`。

## 0. 六条总原则

1. **先定用途**：通行、休憩、遮阴、观赏、生产、儿童活动；不同用途决定铺装与植物密度。
2. **硬景先行**：先做地形、道路、台地、水岸、挡土墙，再种树；不要先摆树后改地。
3. **三层结构**：乔木(冠层) + 灌木/中层 + 地被/花草。三层齐全才像成熟景观。
4. **焦点与对景**：每个空间 1 个主景(大树/水景/雕塑/花境)，入口或路径尽头能看到它。
5. **成组不成行**：植物按 3、5、7 株成簇，大小混龄；禁止棋盘、等距、同高排列。
6. **可维护可通行**：主路 ≥2 格，树枝离地 ≥3 格，刺状植物不进儿童区，视线不被密篱完全遮挡。

> 自然感口诀：**不等距、不同高、不单层、不直线。** 单株是焦点，成组是背景。

## 1. 工作流

1. `get_player_position` + `get_heightmap` 读场地边界与高差, `get_slice` 看现有建筑与铺装。
2. 画功能图：入口、主路、次路、活动区、安静区、种植区、水景、服务角。
3. 做硬景骨架：地形/台地/挡土墙/道路/广场/水岸，用 `fill` 与 `ptc`。
4. 放大树定冠层和天际线；每 10~20 格 1 棵主树，密林 4~9 格、疏林 10~20 格。
5. 种灌木/绿篱/花境，按 3/5/7 株成组，边界用 1~2 格宽绿篱收口。
6. 铺地被：草、蕨、花、苔藓、落叶；草覆盖率草原 30%~40%，森林 15%~20%。
7. 最后做水、灯、座椅、标识、花盆与维护细节；水最后放。
8. `inspect_region` / `get_slice` 检查树根落地、道路连通、植物不穿墙、光 ≥1。

## 2. 尺度速查

| 项目 | 推荐尺寸 |
|---|---|
| 窗台盆栽 | 1×1，花盆 1 格；成组 3 盆 |
| 室内长花槽 | 3~5 格长、1 格宽，沿窗/隔断 |
| 室内树 | 高 5~9，根/冠半径 2~3；上方至少留 3 格 |
| 绿墙 | 宽 3~5 的倍数，厚 1；每 3~5 格换叶种/色 |
| 阳台/露台 | 深 ≥3；种植槽 1 格，保证 2 格通行 |
| 庭院花园 | 9×9 起；主景 3~5 格，路径 1~2 格 |
| 建筑周边种植带 | 深 1~3；靠墙 1 格低植物，外侧放灌木/树 |
| 树间距 | 密林 4~9；疏林 10~20；行道树 6~10 |
| 绿篱 | 宽 1~2、高 1~3；修剪顶用 `slab`/`stairs` |
| 花境 | 3~7 格一段，3~5 种花/叶混种 |
| 步道 | 主路 2~3；小径 1；口袋公园环路 2~3 |
| 座椅区 | 2~3 格净空，背后/侧后方有遮阴 |
| 水景 | 小池 3×3~7×7；中池 9×9~15×15；岸边缓坡 1~2 |

## 3. 植物层次与配色

- **乔木**：橡/云杉/桦/丛林/金合欢/樱花/红树/棕榈；至少 3 种冠形，树高 ±30%。
- **灌木**：`*_leaves` 团块、杜鹃、浆果丛、竹子、仙人掌(旱区)；高 1~3。
- **地被**：`moss_carpet`、`short_grass`、蕨、花、`pink_petals`、落叶；覆盖要成片但留裸土。
- **垂直**：`vine`、`glow_lichen`、`hanging_roots`、藤蔓架、绿墙。
- **水生**：`seagrass`、`kelp`、`waterlily`、`sugar_cane`、`sea_pickle`、珊瑚。
- 配色取环境色：森林=橡木+深绿，樱花=粉+浅木，沙漠=沙+棕+少量绿，现代=灰白+单色绿，奇幻=青绿+发光。
- 绿色层次至少 2 种明度：深绿做背景，中绿做主体，浅黄绿/花做前景。

## 4. 室内绿化

- 房间 ≥1 盆植物；窗边 3 盆成组；大空间角落放 1 棵室内树。
- 盆栽：`flower_pot`、`barrel`、`decorated_pot`；大型槽用 `mud_bricks`/`stonebrick` 围边。
- 绿墙：木框架 + `moss_block` + `azalea`/`leaves` + `glow_lichen`；每 3~5 格留空，避免整墙同色。
- 悬挂：顶部 `chain`/`fence` 挂 `hanging_roots`、`vine`、`big_dripleaf`、花盆。
- 室内树：树干 `*_log`，冠 2~4 团，根不穿地板；树冠下加 `lantern` 2~3 盏。
- 浴室/厨房用蕨、竹、苔藓；卧室用樱花/白花+浅木；书房用深绿+暖灯。
- 植物不能挡门、挡窗、挡主通道；走廊只放壁挂或窄盆。

## 5. 建筑周边与庭院

- 靠墙 1 格低地被，第二 1~2 格灌木，再外侧 2~4 格乔木；层次从低到高，不遮主窗。
- 入口两侧做对称或平衡的 2 组种植池，路径 2~3 格，门前留 2 格回转区。
- 庭院用主景(树/水/雕塑)+ 次景(花境/座椅)+ 路径环线，至少有 1 处坐下歇脚的空间。
- 阳台/屋顶先确认承重与排水；种植槽高 1~2，底部留排水口或 `cauldron`。
- 建筑与绿地交界用 `gravel`/`dirt["dirt_type"="coarse"]`/石缘收边 1 格，避免裸土直贴墙。
- 临水建筑抬高 ≥2 或木桩架空，岸线种 `sugar_cane`/`waterlily`，不要满铺。

详细植物能力表见 **`references/plants.md`**；庭院、绿墙、建筑周边与风格园林见 **`references/landscape.md`**。

## 6. 城市口袋公园

- 常见规模：9×9 微型花园、15×15 邻里口袋公园、25×25~30×30 综合微型公园。
- 五区：入口广场、林荫休憩、草坪/花境、活动场、服务角；至少 3 区，不必都很大。
- 环路 2~3 格，出入口 3~5 格；不允许只有一条断头路。
- 树冠覆盖 30%~50%，中央留 5~9 格视觉焦点(大树/水景/雕塑/草坪)。
- 每 6~10 格一盏灯；座椅成组，背后有树/墙，面向活动或景观。
- 儿童区远离水、仙人掌和陡坡；用 1~2 格围栏/绿篱分隔，留 1 个入口。

三种布局模块、分区尺寸、家具与安全自检见 **`references/pocket-parks.md`**。

## 7. 工具落地与坑清单

- 大范围先 `pin_region`；地形和铺装用 `fill`，植物与花境用 `ptc` 批量提交 `run_server_command` 的 `setblock`。
- 树必须种在可支撑方块上；花必须长在草/土/苔上；藤蔓要有附着面。
- 坑：满屏草方块、树等距、同种同高、绿篱像墙、灌木单点、路径断头、树穿建筑、花覆盖 100%、水岸直线。
- 坑：室内堆 20 盆小盆栽 → 不如 1 棵室内树 + 3 盆成组 + 1 面绿墙。
- 坑：只看单株不看远景 → 先定树冠轮廓，再补下层植物。
- 坑：植物挡门/挡窗/挡招牌 → 交付前从入口和主路走一遍视线。
- Bedrock ID 与植物状态先 `find_items` + `get_block`；大工程忘 `pin_region` 会导致 `fill` 失败。
