# 光照与夜景

> 建造程序里埋灯可以直接用 `api.lib`: `lantern_ceiling(u1, w1, u2, w2, v, spacing)`
> 天花吊灯阵、`chandelier` 吊灯、`floor_lamp` 落地灯、`lamp_post` 路灯、
> `stone_lantern` 石灯笼、`window_seat`/`fireplace` 自带氛围光。
> 这些函数只放光源方块, **隐藏光源(地毯下/半砖下/画后)仍按本手册手埋**。
> 大型建筑的配光与“门前必加灯、庭院中心必加泉”的装饰守则, 见技能 `mc-build` 的
> `references/mega-build-guide.md`【三】。

## 1. 先记住两条硬规则

- **方块光从 15 起，每向外一格衰减 1**（穿过的方块会挡光，玻璃不挡，水会衰减）。
- **基岩版敌对生物在光照 ≤7 的地方生成**。所以室内、地下室、封闭庭院的有效光照 **≥8** 才安全；
  想让人看清细节，走道 ≥10，主要活动区 ≥12。

检查手段：`get_slice` 看灯位是否均匀、`inspect_region(filter=glowstone)` 数灯，
或 `run_server_command("time set night")` 后让玩家看，再 `time set day` 还原。

## 2. 光源亮度表（基岩版）

| 亮度 | 方块 |
|---|---|
| 15 | 萤石、海晶灯、南瓜灯、灯笼、营火（点燃）、岩浆、蛙明灯、菌光体、红石灯（通电） |
| 14 | 火把、末地烛、海晶灯（水下也亮） |
| 12~15 | 蜡烛（1 支 3，每加一支 +3，4 支 12；插在蛋糕上另算） |
| 10 | 点亮的营火（被水浇灭后 0）、发光浆果？不发光——用发光的**发光地衣 7**、**荧光墨**类装饰 |
| 7 | 发光地衣（只能贴面，做痕迹光） |
| 1 | 岩浆块（不发亮但会烫）、红石火把 7（不要用，容易误触） |

> 需要"看不见灯、但有光"时优先 **萤石 + 半砖/地毯/楼梯遮盖**，或 **海晶灯埋在水下**。
> 营火/灵魂营火有烟与声响，适合户外氛围但别放在木结构里。

## 3. 隐藏光源配方（最常用）

| 场景 | 做法 |
|---|---|
| 地板发亮 | 地面挖一格 → 放萤石 → 上面盖**半砖**（同材质）或地毯 |
| 天花板无灯 | 天花板夹层放萤石，每隔 4~5 格一个，下面用半砖封 |
| 墙脚洗墙光 | 楼梯下藏萤石（楼梯背面朝外），光线从缝隙溢出 |
| 树下/绿墙 | 树叶间塞萤石或海晶灯（不要塞火把，会烧到视觉上） |
| 水下照明 | 海晶灯直接埋水底，或玻璃罩住 |
| 展示柜重点光 | 物品展示框上方一格藏萤石，上方再盖半砖 |

在建造程序里埋灯（不用手算坐标）：

```python
# 每 5 格铺一盏地灯: 地板下埋萤石, 上面盖平滑石半砖
for u in range(0, W, 5):
    for w in range(0, D, 5):
        api.set(u, 0, w, "glowstone")                       # 地板层
        api.set(u, 1, w, "smooth_stone_slab", {"top_slot_bit": True})  # 盖住
```

## 4. 配光法（三层次）

1. **主光（功能）**：保证光级，均匀铺，别让人看出灯在哪。
2. **辅光（氛围）**：灯笼、蜡烛、营火，做暖色点缀；间距 6~10 格，不要每根柱子都挂。
3. **重点光（叙事）**：展品、招牌、入口、神龛——单独打亮，周围压暗，形成对比。

色温搭配：

- **暖**（2700K 观感）：火把、灯笼、营火、南瓜灯 → 木构、民居、酒馆
- **冷**（6000K 观感）：海晶灯、灵魂火/灵魂灯笼、末地烛 → 神殿、冰宫、科技风
- 冷暖混用只在"室内暖 / 室外冷"这种分层时用，同一空间别混。

## 5. 外景与夜景

- **路灯**：间距 8~12 格（太密像跑道，太疏有暗区）；灯杆高 3~5 格，灯头朝下。
- **庭院地灯**：地面埋萤石 + 半砖，间距 4~6 格，沿路两侧错开。
- **水面倒影**：灯离水面 2~4 格最出效果；水面越大，灯越少越亮眼。
- **夜景重点**：主建筑轮廓用"洗墙光"（楼梯后藏灯），别用一排火把勾边。
- **月亮方向**：主立面朝东/南，夜里也有环境光可借。

## 6. 常见坑

| 问题 | 原因 |
|---|---|
| 埋了灯还是不亮 | 灯被**实体方块整格盖住**（半砖/楼梯/地毯可以透光，整块不行） |
| 局部还是刷怪 | 光级 7 及以下；角落、床下、楼梯下要单独补 |
| 玻璃房晚上发黑 | 玻璃不挡光但**不产光**，室内仍需光源 |
| 水下灯不亮 | 水会衰减光；用海晶灯或把灯放在水面以上照下来 |
| 火把烧掉木屋 | 火把不会点燃方块，但视觉上别贴在木梁上；营火会冒烟 |
| 灵魂火把偏蓝 | 那是刻意的冷色光源，别和暖光混在同一房间 |
