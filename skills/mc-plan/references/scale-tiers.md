# 规模档位与目标方块数

本手册把“AI 建筑规模”分成三档，并给每档一个**目标方块数区间**（不是硬上限，而是
“这次大概要做到多大”），生成时随机落在区间内。它的价值在于：**先定体量，再定构件**，
避免“用建小屋的思路去建宫殿”或反之。

## 1. 三档

| 档位 | 名称 | 目标方块数 | 方块的“感觉” |
|---|---|---|---|
| 0 | 中小型建筑 | 1,000 ~ 10,000 | 民居、商铺、塔楼、亭子、小教堂 |
| 1 | 大型建筑 | 10,000 ~ 500,000 | 城堡、修道院、大教堂、宫殿单体 |
| 2 | 超大型建筑 | 500,000 ~ 1,600,000 | 建筑群、城镇、大型园林、地形改造 |

补充口径（本手册代码里的常量）：

- 硬上限：中小型 10,000 / 大型 500,000 / 超大型 1,600,000；
- 上限地板：1,000（再小的配置也不低于它）；
- 每次生成的实际目标 = 在区间内取随机值；设计容量取 `goal × 1.3`，再夹到档位上限。

## 2. 往项目里的换算

本项目的单次 `build_commit` 受 `MAX_VOLUME / MAX_CELLS = 65536 格` 限制，所以：

- **档位是“整栋/整片”的目标**，不是“一次提交”的量；
- 超大型 = 多次提交的总和，必须按模块/分区切分（见 `mc-plan` 的分区策略）；
- 一栋 10 万方块的主楼 = 大约 2 次满额提交 + 若干细节补丁；
- 目标方块数用来**估工期与分几次做**，不要试图一次 preview 全部。

估数量公式（用于估算）：

```
所需建筑数 = 目标方块数 ÷ 单体方块数
```

| 整栋模板 | 单体方块数（参考） |
|---|---|
| 小屋 / 民居 | ≈400 |
| 酒馆 / 面包房 | ≈800 |
| 教堂 | ≈1800 |
| 城堡主楼 | ≈2500 |
| 城门 | ≈600 |
| 风车 | ≈500 |
| 集市摊位 | ≈120 |
| 灯塔 | ≈900 |
| 城墙 | ≈8 × 长度 |
| 地下大厅 | ≈2000 |

例：100 万方块 ≈ 2000 栋中世纪民宅，或 500 栋房屋 + 2000 米城墙 + 50 座功能建筑。

## 3. 项目里的用法

1. 玩家说“建个城堡”→ 先判档位（大型），给一个 1~5 万的量级预期，而不是直接全量 preview；
2. 按模块切：地基 → 墙身/塔 → 屋顶 → 内部 → 环境，每个模块单独 `build_preview`；
3. 超大型（城镇/建筑群）：先做 2~3 栋样板确认风格，再用循环批量生成变体
   （本手册红线：**原样复制不得超过 3 份**）；
4. 报完成时给玩家“大概多少方块 / 分几段建 / 还剩哪些区”，而不是只说“建好了”。
