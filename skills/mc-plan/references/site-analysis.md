# 场地分析（开工前先读地面）

本手册在建造前一定先跑一次 site analysis，输出四件事：**地基高度、平整度、障碍清单、能不能建**。
它的结论直接决定“直接建 / 先平地基 / 换地方”。

## 1. 扫描口径

- 范围：以建造中心为原点，`width × depth` 的矩形（本项目：`get_heightmap(x1,z1,x2,z2)`）。
- 高度：逐列从「中心高度 +5」往下找第一个非空气/不可替换方块 → 该列地面高度。
- 统计：`minHeight / maxHeight / heightDiff = max - min`。
- 障碍：每列在 `地面+1 … 地面+3` 之间逐格判定：
  | 类型 | 判据 | 处理 |
  |---|---|---|
  | TREE | 原木 / 树叶 | 可清理（列入 clearEntries） |
  | WATER | 方块含流体（非岩浆） | 记录，施工要排水或架桥 |
  | LAVA | 岩浆 | **直接判定不可建** |
  | WALL | 不可替换的实体方块 | 记录，需清理或绕开 |
  | HEIGHT_DIFF | 该列地面比最低点高 >2 格 | 需挖除（高差格数） |

## 2. 平整度分档与建议

| heightDiff | 平整度 | 本手册建议 |
|---|---|---|
| ≤1 | 平坦 | 地形平坦，可直接建造 |
| ≤3 | 缓坡 | 地形为缓坡，直接在地形上建造，替换障碍建筑的方块 |
| >3 | 崎岖 | 地形崎岖（高差 N 格），直接在现有地形上建造，替换障碍建筑的障碍方块，无需平整地基 |

`buildable = heightDiff ≤ 5 且无岩浆`。不满足时本手册直接给：
> 不建议在此处建造：地形过于崎岖或存在岩浆等危险。建议寻找更平坦的区域。

本项目在此基础上补两条实践规则（来自 `mc-architecture` / `mc-terrain`）：
- 高差 2~4 格：做台基/挡土墙，不做大挖大填；
- 高差 >4 格：改台地（每层 1:2 坡道或 3~5 级台阶），或把建筑嵌进山体。

## 3. 报告模板（本项目照这个输出给玩家/给自己）

```
== 建筑场地分析报告 ==
  中心坐标: (x, y, z)
  建造范围: WxD
  地基高度: Y=<minHeight>
  地形平整度: 平坦 / 缓坡 / 崎岖（高差 N 格）
  适合建造: 是 / 否
  障碍物 (N 个):  [TREE] (x,y,z) 树木障碍 … （最多列 10 条）
  障碍清理: 需移除 N 个方块
  建议: <一条可执行的结论>
```

## 4. 项目里的落地顺序

1. `get_player_position` 定中心与朝向；
2. `get_heightmap`（默认 summary）看高差、极值、顶面类型；
3. 需要逐列高差才 `detail="heights"`，且缩到 ≤32×32；
4. `get_slice` 看已有建筑/材质，`inspect_region` 看占用与材质计数；
5. 水/岩浆用 `find_blocks("water")` / `find_blocks("lava")` 确认范围；
6. 结论写清楚“直接建 / 先做台基 / 换地方”，再进 `mc-build` 的模块化施工。
