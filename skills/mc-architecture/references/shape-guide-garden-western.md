# ShapeGuide · shape-guide-garden-western

圆明园式「中式园林 + 西洋石构」双语汇: 西洋楼石构、水景(大水法)、园林构筑
(石舫/九曲桥/叠石假山/游廊/花池), 以及西洋楼立面、水景、园林组团三套套路。

## ★圆明园构件（玩家说"圆明园/西洋楼/大水法/海晏堂/黄花阵/石舫/九曲桥"就照这做）
★ 圆明园是**两种语言拼在一座园子里**，不要用同一种语汇糊完整座园：
  · 中式（九州景区、后湖）：木构 + 曲面屋面 → 仍用 chineseRoof 那一套
  · 西洋（长春园西洋楼景区）：**石头做的平立面 + 柱式 + 山花 + 卷涡** → 用下面这批
  把中式屋顶盖到西洋石楼上，或者反过来，是最典型的"看着不像圆明园"的原因。
★ 材料纪律：西洋楼一律**汉白玉**（smooth_quartz / quartz_bricks / chiseled_quartz_block），
  线脚用 quartz_pillar 或 quartz_bricks；**不要**给西洋楼配黄琉璃或朱红——
  琉璃和朱红是中式宫殿的，西洋楼是灰白石材。

【一、西洋楼石构】
· classicalColumn(cx, z, 底面Y, 总高, 柱径, 柱方块, 柱头方块)
  古典柱（自带柱础外扩、柱身上段收分、柱头两层外扩）。柱径 1~3，总高 ≥4。
  柱子是**独立**一根；成排的柱廊用下面的 baroquePortico，不要循环调它去凑。
· baroquePortico(x1, z1, 台基顶Y, 柱数, 柱高, "north"/"south"/"east"/"west", 石方块, 线脚方块)
  巴洛克门廊**一次成片**：柱列 + 额枋（比柱列外挑 1、厚 2）+ 三角山花（逐层收窄）。
  柱数给奇数（3 三开间、5 五开间）；台基顶Y 是门廊起步的那一层，下面是你要自己铺的台基。
  facing 填**门廊正对**的方向；它是**单面**构件（贴在已有墙上，不出背面）。
  ★ 要求 x1→z1 这个方向上的跨度 ≥ 柱数×2，否则不出块（会静默返回 0）。
· volute(cx, cy, cz, 半径, +1或-1, 方块)
  卷涡（巴洛克山花两端的螺旋）。半径 3~5；side +1 / -1 决定往哪边卷，
  山花**两端各放一个、方向相反**才对称。它只出螺旋本体，圆心会自动补一格"眼睛"。
· balustrade(x1, z1, x2, z2, 底面Y, 柱距, 柱方块, 扶手方块)
  宝瓶栏杆（基座 + 花瓶柱 + 扶手，共 4 层高）。柱距 2~4。
  ★ 和 railing 的区别：railing 是中式望柱栏板（2 层），balustrade 是西洋石栏（4 层、
    逐根收腰）。西洋楼的屋顶边、露台边、水池边**必须用它**，用 railing 会变中式。
· archedWindow(cx, cz, 窗台Y, 宽, 矩形段高, facing, 框方块, 玻璃方块)
  拱券窗（矩形段 + 半圆券 + 券心石凸出 + 窗台每边宽 1）。
  宽给奇数 3/5/7；矩形段高 2~4（券会再加半宽那么高）。facing 填**窗朝外**的方向。
  ★ 它只贴一层皮（不挖洞），所以要么建在墙上当装饰，要么先 fill 留洞再套上去。
· pilasterStrip(x1, z1, x2, z2, 底Y, 顶Y, 间距, facing, 方块, 柱头方块)
  壁柱带：沿这面墙每隔几格竖一道**凸出墙面 1 格**的窄柱，把"一块板"分成几个开间。
  ★★ 这是西洋立面**性价比最高的一招**——墙面太素时先加它，不要先去雕花。
  间距给 3~6；facing 填**墙的外法线方向**（柱会往这个方向凸出去）。
· cornice(x1, z1, x2, z2, 起始Y, 每层外挑, 层数, 方块)
  檐口线脚：墙顶一圈逐层外挑的水平带（挑 1 → 挑 2 → 挑 3）。每层外挑给 1，层数 2~4。
  ★ 立面"收不住头"、看起来像一块立起来的板，八成就是缺这道cornice。
  ★ 坐标反着给（x1>x2）也能正常工作，不用自己调换。

【二、水景（大水法 / 海晏堂 / 黄花阵一带）】
· waterBasin(x1, z1, x2, z2, 池底Y, 池壁高, 壁方块, 底方块, 水方块)
  方形水池，**池底/池壁/水面三层齐全**，水面自动落在池壁顶下方 1 格。
  池壁高 ≥2。底方块给 null 就用壁方块；水方块给 "water"（枯水池可换 sand）。
· roundBasin(cx, cz, 池底Y, 半径, 池壁高, 壁方块, 水方块)
  圆形水池（水法基座用）。半径 ≥3（含 1 格池壁），池壁固定 1 环。
· cascade(cx, cz, 顶层Y, 宽, 层数, 每层落差, 每层外挑, 石壁方块)
  跌水：**逐层水平水槽 + 垂直落水 + 逐层往外挑**。宽给奇数 3~7，层数 2~6，落差 2~4，外挑 1。
  ★ 从 cz 往 **+Z 方向**一层层往外跌，所以 cz 要放在水法的背面、朝向观众的那一侧。
  ★ 不要用"一列竖直 water"代替它 —— 那会变成一根水柱，不是水法。

【三、园林构筑（石舫 / 九曲桥 / 叠石假山 / 游廊 / 花池）】
· zigzagBridge(x1, z1, x2, z2, 桥面Y, 折数, 桥宽, 桥面方块, 栏杆方块)
  九曲桥：折点交替横向偏移，**转角自动补实**（不会走过去掉水里）。
  折数给 3~9（奇数更像"九曲"），桥宽给奇数 3。栏杆给 null 就不加。
  ★ 两端点之间**至少要比折数宽**，太短会退化成一条直线。
· stoneBoat(cx, cz, 甲板Y, 船长, 船宽, 船体高, 舱房高, 船体方块, 舱方块, 顶方块)
  石舫（画舫）：平底方头船体 + 中段舱房（内部自动挖空）+ 两级外挑顶棚。
  船长沿 **Z** 7~25，船宽沿 X 5~13，舱房高 ≥3。
  ★ 甲板Y 放在水面那一层或略高；船体高是水线以下的格数。
· rockery(cx, cz, 底面Y, 半宽X, 高, 半深Z, 镂空密度, 外层方块, 内层方块)
  叠石假山（太湖石）：上收下阔 + **内部真挖穿**（整数取模，确定性）。
  半宽/半深 ≥3，高 ≥4 且**要大于半宽**（假山要高瘦，矮胖就是汤圆）。镂空密度 2~6。
  ★ 千万不要用 sphere/ellipsoid 做假山 —— 出来是个球。
· coveredWalkway(x1, z1, x2, z2, 地面Y, 廊宽, 柱高, 柱距, 柱方块, 廊顶方块, 坐凳方块)
  游廊：廊顶（外挑 1）+ 廊地面 + 两侧柱 + 美人靠坐凳。
  廊宽 3~7（奇数），柱高 ≥3，柱距 3~5。坐凳给 null 就不做。
  ★ 自动沿主轴延伸（X 或 Z 哪边长就走哪边），斜着给也会铺但会退化成阶梯。
  ★ 和 colonnade 的区别：colonnade 是**无顶**的开敞柱廊（西洋古典），
    游廊是**有顶、有坐凳**的（园林）。圆明园里廊比殿多，成套建筑之间用廊连起来。
· flowerBed(x1, z1, x2, z2, 地面Y, 池壁高, 壁方块, 土方块, 花方块, 间距)
  花池：石池壁 + 内部土 + 按"间距"散布的花（间距 2~4）。池壁高 1~2。
  ★ 池壁从**地面Y 这一层**就开始，所以斜坡上也封得住，不会有悬空一圈。

【★西洋楼立面套路（玩家说"西洋楼/巴洛克/海晏堂/远瀛观"就照这个做）】
a. 台基：fill 一块**实心**石台基（smooth_quartz），高 2~3；
   台基前沿用 steppedTerrace 做几级台阶，台基顶边用 balustrade 围一圈。
b. 墙身：**平墙**（就是这个景区该是平的），颜色只有灰白石材；
   先用 fill 把墙建到设计高度，**先留好窗洞**（不留洞也可以用 archedWindow 贴皮）。
c. 竖向分隔：整面墙调 pilasterStrip（间距 4~6，facing = 墙的外法线）——
   先做这一步，立面立刻从"一块板"变成"几开间"。
d. 窗：每个开间正中放 archedWindow（宽 3 或 5，矩形段高 3），
   全部用同一个窗台Y，**高度必须齐**（错一层就毁了）。
e. 檐口：墙顶调 cornice（层数 3、每层挑 1）。这一步做完立面才有"帽"。
f. 门廊：正面居中用 baroquePortico（柱数 3~5，柱高 = 墙高的 0.6~0.8）。
g. 山花两端：在 baroquePortico 山花的**左右两个端点**各放一个 volute，
   一边 side=+1、一边 side=-1。注意 volute 的 cy 取山花腰线那一层。
h. 屋顶：西洋楼是**平顶/低坡顶**，不要盖 chineseRoof！顶面用 fill 铺石材，
   周围一圈 balustrade 收边；想要断墙残柱的"遗址感"就故意留几段墙不建完。
i. ★比例纪律（西洋立面像不像，看三条）：
   · 柱高 : 门廊总宽 ≈ 1 : 3 ~ 1 : 4（门廊太窄会像门套）
   · 窗宽 : 窗间距 ≈ 1 : 1（窗排太密就像仓库）
   · 檐口挑出总量 ≈ 3 格（挑太少看不出，挑太多变中式飞檐）

【★大水法 / 水景套路】
1) 主池：roundBasin（半径 6~10）或 waterBasin（方形大池）；
2) 池心：中间起一座石台（fill），台上放 statueGroup 或一座小塔当水法主体；
3) 跌水：从池后侧的高台用 cascade 往池里逐层跌（外挑 1、落差 2~3）；
4) 边框：池沿一圈 balustrade，池外四面铺 flowerBed 或 gardenPath；
5) 轴线：整组水景要和主楼**同一条中轴**，两边对称地再各放一个小 roundBasin。
★ 水面比池沿低 1 格是函数自动做的，不要自己再抬高水面。

【★园林组团套路（让园子"成园"而不是"散落几个建筑"）】
1) 先定一条**环湖路**：gardenPath 绕一圈，园子就有了骨架；
2) 湖：waterBasin 做不规则湖（用 2~3 个矩形叠出来），岸边 rockery 叠石收边；
3) 桥：湖面最窄处架 zigzagBridge（折数 5 或 7），通向对岸；
4) 廊：把 2~3 座建筑用 coveredWalkway 连起来 —— 这是"园"和"建筑群"的分水岭；
5) 点景：水边 stoneBoat，墙角 rockery，空地 flowerBed，树下 pagoda 或亭子；
6) 密度纪律：**建筑占三成、水与石占三成、绿化与空场占四成**。
   全铺满建筑是"小区"，不是园林。

【圆明园不要做的事】
· 不要给西洋楼盖中式曲面屋顶、不要配黄琉璃和朱红（那是故宫的语言）；
· 不要用 railing 代替 balustrade（中式望柱 ≠ 西洋宝瓶栏）；
· 不要用 sphere/ellipsoid 做假山，也不要用 fill 手搓假山（一定是方块球或方块堆）；
· 不要用一列竖直 water 做瀑布/水法（那是水柱）；
· 不要把整个园子铺满建筑 —— 园林的主体是水、石、树，不是房子。
