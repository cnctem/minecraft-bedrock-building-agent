> 函数名两种写法都能用: `api.lib.chineseRoof(...)` 与 `api.lib.chinese_roof(...)`;
> 参数里的 `{...}` 是选项名清单, 在本项目里写成关键字参数(见 `api.lib.help("名字")`)。

# 中式建筑造型指导

中式（官式 + 八个地域流派）的构件选择、比例与组合套路。**先读「流派路由」**，
再按玩家说的地域/等级取用构件；不要默认故宫。

## ★中国建筑构件函数（官式 + 地域流派；不要用 fill 手搓曲线）
这些函数已经算好了曲线与收分，你只需要给范围和材料。参数里的坐标一律是**相对原点**。

## ★★中式流派路由（第一步必做：先判断是哪个流派，不要默认故宫）
★★★「中式建筑」**不是一种风格**。中国有至少八九个地域流派，它们的屋顶、山墙、
  材料、比例完全不同。**玩家只说「中式 / 古风 / 中国风」时，绝对不要直接照故宫做**——
  先把这句话里的地域线索找出来，再按下面的表选。
★ 只有玩家说出「故宫 / 紫禁城 / 皇宫 / 太和殿 / 宫殿 / 大殿 / 庙宇」时，
  才走官式（斗拱 + 须弥座 + 黄琉璃）那一套；否则一律按民居流派做。

【按玩家的话选流派】（找到关键词就按那一行做全套）
· 江南 / 水乡 / 苏州 / 杭州 / 周庄 / 乌镇 / 园林 / 徽州以外的小镇
  → 江南民居：**白墙黛瓦**（smooth_quartz 白墙 + deepslate_tiles 青瓦）
    标志构件：guanyinDou（观音兜山墙，连续弧、中间最高）、riverSteps（河埠头石阶）、
             meirenKao（美人靠湾椅）、moonGate（月洞门）
    屋顶：chineseRoof「硬山/悬山」+ 青瓦。**不要**用黄琉璃、不要用斗拱。
· 徽州 / 徽派 / 西递 / 宏村 / 马头墙 / 天井
  → 徽派：白墙青瓦 + **阶梯山墙**
    标志构件：horseHeadWall（马头墙，两端最高、一级级下降）、skyWell（天井四水归堂）、
             brickGatehouse（砖雕门罩）、screenWall（影壁）
    屋顶：硬山，青瓦。马头墙必须**两端高**——这是徽派和江南最容易混的地方。
· 闽南 / 福建 / 潮汕 / 泉州 / 漳州 / 红砖 / 燕尾
  → 闽南：**红砖 + 燕尾脊**（terracotta / orange_terracotta）
    标志构件：swallowtailRidge（燕尾脊，**两端上翘并分叉**，整条脊中段是平的）
    屋顶：硬山，红瓦。★燕尾脊是中式里唯一「两端比中间高」的脊，别用 ridgeBeasts 代替。
· 广东 / 岭南 / 广府 / 镬耳 / 骑楼
  → 岭南：青砖灰瓦 + **镬耳山墙**
    标志构件：huoerWall（镬耳墙，中间平、两端各一个锅耳半圆）
    屋顶：硬山，青瓦。★镬耳墙 ≠ 观音兜：镬耳是「中间平 + 两端半圆」，观音兜是整条连续弧。
· 四川 / 川蜀 / 重庆 / 西南 / 吊脚楼 / 穿斗
  → 川蜀：木构本色 + 青瓦，**柱密、有穿枋、无斗拱**
    标志构件：chuandouFrame（穿斗木构：密柱 + 贯通穿枋）、stiltHouse（吊脚楼：架空楼板）
    屋顶：chineseRoof「悬山」或 curvedRoof，青瓦。★不要加 dougong（那是官式）。
· 西北 / 陕北 / 延安 / 窑洞 / 黄土高原
  → 西北窑洞：**土黄**（packed_mud / mud_bricks）
    标志构件：yaodong（窑洞：完整土崖立面 + 半圆券门洞 + 上部退台）
    屋顶：**平顶**，不要加任何曲面屋顶。★门洞必须是半圆券，方口就不是窑洞了。
· 西藏 / 藏式 / 拉萨 / 布达拉 / 碉房 / 藏族
  → 藏族：石墙 + **梯形收分** + 顶部棕红边玛墙
    标志构件：tibetanFort（碉房：下宽上窄 + 顶部棕红边玛墙檐带）
    屋顶：**平顶**（可加金顶，但不要中式曲面屋顶）。
· 客家 / 土楼 / 围屋 / 福建圆形楼
  → 客家：夯土 **圆环**建筑
    标志构件：tulou（土楼：环形厚墙 + 中心内院 + 逐层环廊 + 环形瓦檐）
    ★tulou 自带瓦檐，**不要再盖 chineseRoof**（会变成奇怪的尖顶）。

【三条跨流派的纪律】
· **颜色**：黄琉璃（yellow_glazed_terracotta）**只属于皇宫**。民居用青瓦（deepslate_tiles）、
  灰瓦（gray_concrete）、红瓦（terracotta）或茅草。给江南民居配黄琉璃 = 一眼假。
· **等级**：斗拱（dougong）、须弥座（sumeruBase）、重檐屋顶（重檐庑殿/重檐歇山）、
  藻井（caissonCeiling）都是**官式等级符号**。民居用它们会变成"缩小版的宫殿"，
  这正是"中式一律做成故宫"的由来。
· **地域词优先于体量**：玩家说「江南小镇」哪怕是十座房子，也全用江南语汇；
  玩家说「小庙」也要用官式语汇（庙是官式建筑）。别按大小猜风格。

## 官式构件（屋顶 / 斗拱 / 台基 / 门窗 / 塔）

【屋顶】★做中式屋顶**首选 chineseRoof**，它一个函数就把「举折凹曲 + 屋面水密 +
正脊/垂脊 + 瓦垄 + 四角起翘 + 檐口勾边」全做完；分散调用那几个单件很容易对不齐参数。
· chineseRoof(x1, z1, x2, z2, 檐口Y, 高度, 形制, 瓦方块, 脊方块)
  形制只填中文词，六选一：
    「庑殿」= 四面坡+一条正脊（最高等级）｜「歇山」= 下段四面坡+上段两坡+垂直山花
    「攒尖」= 收成一点（亭子/角楼）｜「悬山」/「硬山」= 只有前后两坡、山面自动补三角
   ★ 故宫那种"一进院"里，正殿用「重檐庑殿」，配殿/廊庑/值房用「悬山」小体量——
     全用大殿式屋顶会让整个院落失去层次。
    「重檐庑殿」= 下檐+腰+上檐（★故宫太和殿就是它，做宫殿/大殿必须用这个）
    「重檐歇山」= 同上，上檐换歇山（天安门、城楼、宫门用）
  瓦方块：黄琉璃用 yellow_glazed_terracotta（故宫）／青瓦用 deepslate_tiles、gray_concrete
  脊方块：正脊垂脊压顶，深色更立体，如 deepslate_tiles、polished_blackstone
  ★ 屋面已经是**双面连续曲面**（从下面看不会漏、不是一摞方框），自带瓦垄、
    **自带四角起翘**、**自带檐口一圈脊色勾边**，所以**不要再**另外调
    tileRidges / flyingEave / ridgeBeasts 去补——会重复堆方块、把翘角堆成尖刺。
  ★ 屋顶函数只出屋面，墙身要自己先建到「檐口Y」这一层。
  ★★ 尺寸比例（给错比例是"屋顶难看"的头号原因，比形状选错还致命）：
     · 高度 = 进深（短边跨度）× 0.35 ~ 0.45，且 ≥4、≤ 短边的一半
     · 屋顶平面要比墙身**每边外挑 2~4 格**（出檐），x1/z1/x2/z2 直接给外挑后的范围
     · 重檐只给**总高**：内部按 下檐 40% → 腰 → 上檐 收进 16% 自动切，不要再自己拼两段
     · 面宽 : 进深 别做 1:1（正方屋顶看不出"庑殿"和"攒尖"的区别）
· curvedRoof(x1, z1, x2, z2, 檐口Y, 高度, 方块)
  单一方向的凹曲屋面（两坡，从前后檐起坡）。做长廊、配房、厢房的屋顶。
· flyingEave(x1, z1, x2, z2, 檐口Y, 抬高格数, 影响范围, 外挑格数, 方块)
  飞檐翘角：沿檐口铺一圈，**四角**上翘外挑（角部抬满、往两边衰减）。
  ★ chineseRoof 已内置一档起翘；只有想要**更夸张**的角才在它的檐口 Y 上再叠一层。
· xieshanRoof(x1, z1, x2, z2, 檐口Y, 高度, 山花起点比例, 方块)
  歇山顶单件版（比例通常 0.55）。没有瓦垄与脊，正式建筑请优先 chineseRoof「歇山」。
· hipRoof(x1, z1, x2, z2, 檐口Y, 高度, 方块)
  庑殿顶单件版。正脊自动沿**长边**（南北长的建筑脊就南北向）。
· pyramidRoof(cx, cz, 檐口Y, 半宽, 高度, 宝顶高度, 屋面方块, 宝顶方块)
  攒尖顶单件版（收成一点 + 宝顶）。宝顶给 gold_block / sea_lantern 最像。

【斗拱与台基】
· dougong(cx, cy, cz, 起始半径, 层数, 方块)
  斗拱。柱头上一层层向外挑出的托块，中式建筑"层层叠叠"观感的来源。
  放在每根柱子的顶端，层数 2~4。
· sumeruBase(x1, z1, x2, z2, 底面Y, 高度, 方块)
  须弥座台基（上宽、中间束腰收进、下宽）。整座建筑先铺这个再往上建。
· railing(x1, z1, x2, z2, 地面Y, 望柱间距, 方块)
  栏杆（望柱高 2、栏板高 1）。台基边缘、月台、桥面用。

【门窗与塔】
· moonGate(cx, cy, cz, "x"或"z", 半径, 门套方块)
  月洞门。axis="x" 表示墙沿 X 延伸（门洞法线朝 Z）。圆洞会**真挖空**（写 air），
  所以它必须用在**已经建好的墙上**。
· pagoda(cx, cz, 底座Y, 底层半径, 层数, 每层高, 边数, 塔身方块, 出檐方块)
  塔。多层多边形筒 + 逐层收分 + 每层出檐 + 塔刹。边数用 4/6/8。

【组合套路（照着做就不会错）】
★ 下面第一组是**官式**（宫殿/寺庙/塔/亭），第二组是**地域民居**。
  按上面的流派路由先选组，别把两组的语汇混着用。

· 一座**官式**殿宇：
  1) sumeruBase 铺台基；
  2) 在台基上围墙（fill 或 wall）+ 前墙用 moonGate 开月洞门；
  3) 柱列用 colonnade，每根柱顶加 dougong；
  4) 屋顶用 curvedRoof，再在檐口铺 flyingEave；
  5) 台基边缘加 railing。
· 一座亭子：pyramidRoof + 四角柱 + sumeruBase + railing。
· 一座塔：pagoda 一次成型，再在底层加 moonGate。
· 歇山/庑殿的**底座**要先有墙：屋顶函数只出屋面，不出墙。

· 一座**江南民居**（一层，临水）：
  1) 墙身：smooth_quartz 白墙（fill 四堵墙，高 3~4），山墙用 guanyinDou 收弧形顶；
  2) 屋顶：chineseRoof「硬山」+ deepslate_tiles 青瓦（高度 = 进深×0.35，别做高）；
  3) 临水一面做 meirenKao（靠水侧），再往外接 riverSteps 下到水里；
  4) 门窗：moonGate（院墙）或 windowUnit（住房）。
  ★ 配色只有白+黑+木本色。**加黄琉璃或朱红就不是江南了**。
· 一座**徽派民居**：
  1) 白墙（smooth_quartz）+ 两侧山墙用 horseHeadWall（级数 3，**两端最高**）；
  2) 屋顶硬山青瓦，屋面**朝院内**倾斜（四水归堂）；
  3) 院子中心 skyWell（下沉 2~3，底铺 water）；
  4) 大门用 brickGatehouse（砖雕门罩），门外正对 screenWall（影壁）。
· 一座**闽南民居/祠堂**：
  1) 红砖墙（terracotta / orange_terracotta），正面开大石框门；
  2) 屋顶硬山红瓦，**正脊两端用 swallowtailRidge**（端点抬高 4~6，两端上翘分叉）；
  3) 檐下可加一点石雕线脚（chiseled_stone_bricks）。
  ★ 闽南的辨识点就在那条**上翘的燕尾脊**，没有它就不是闽南。
· 一座**岭南民居**：
  1) 青砖墙（gray_concrete / stone_bricks），两侧山墙 huoerWall（耳抬高 3~5）；
  2) 屋顶硬山青瓦，进深**浅**（岭南房子窄而深，配天井通风）；
  3) 窄巷（冷巷）两侧贴墙，宽 2~3 格即可。
· 一座**川蜀民居/吊脚楼**：
  1) 临坡/临水处 stiltHouse（架空 2~3，柱 dark_oak_log，楼板 dark_oak_planks）；
  2) 构架用 chuandouFrame（开间 3~5，**不要加 dougong**）；
  3) 屋顶 chineseRoof「悬山」或 curvedRoof，青瓦（deepslate_tiles）。
· 一座**西北窑洞院落**：
  1) 土崖立面 yaodong（立面高 5~7，拱半径 3）；
  2) 院子平顶，围墙用 packed_mud；
  3) **不要盖任何曲面屋顶**，平顶上可以放晒台（台阶）。
· 一座**藏式碉房**：
  1) tibetanFort（收分 0.1~0.15，顶部边玛墙 red_terracotta）；
  2) 平顶，顶上可加经幡杆（flagBanner）；
  3) 窗做成小方口、均匀排布（藏式窗小而密）。
· 一座**客家土楼**：
  1) tulou 一次成型（外半径 10~14，层数 3~4，墙厚 3）；
  2) 内院中心可加一口井（well）或祠堂小体量；
  3) ★不要再盖屋顶 —— tulou 自带环形瓦檐。

【不要做的事】
· 不要用 sphere/dome 做中式屋顶（那是穹顶，不是反宇）；
· 不要用 pyramid 做攒尖顶（pyramid 是实心四棱锥，没有收分曲线也没有宝顶）；
· 不要自己用 fill 循环去拼斜屋面 —— 台阶会漏、曲线也会变成直线。
· 不要用 fill 手搓**柱式/券窗/卷涡/栏杆/假山/水池**：西洋古典构件（classicalColumn /
  baroquePortico / volute / balustrade / archedWindow / pilasterStrip / cornice）、
  水景（waterBasin / roundBasin / cascade）、园林构筑（zigzagBridge / stoneBoat /
  rockery / coveredWalkway / flowerBed）都已有专门函数，见下面的「圆明园构件」一节。
  手搓只会得到"立面全平"和"卷涡搓成锯齿"这两个固定失败模式。

## ★古建细部（屋顶做了 curvedRoof 之后必须补这几样才像中国建筑）
· tileRidges(x1, z1, x2, z2, 檐口Y, 屋脊高, 每几列一条, 方块)
  瓦垄：屋面上一条条竖向瓦条。**只配 curvedRoof 用，参数必须和它逐字一致**，
  否则瓦条会浮在屋面外面。每几列一条通常给 2。
  ★ 用 chineseRoof 时**不要**再调它（它已自带瓦垄），否则瓦垄叠两层。
· ridgeBeasts(x1, z1, x2, z2, 脊顶Y, 小兽数量, 方块)
  屋脊吻兽：两端各一个高 2 的鸱吻 + 中间等距小兽。
  正脊做完就加它，屋顶立刻"活"起来。
· caissonCeiling(cx, cy, cz, 半宽, 层数, 方块, 井心方块)
  藻井：天花中心逐层内收的方井 + 井心明镜（常用金块）。
· sparrowBracket(cx, cy, cz, "x"或"z", 长度, 方块)
  雀替：柱与梁交角的三角形托座。上宽下窄，每根柱头加两片（两个方向）。
· hangingLattice(x1, y, z1, x2, z2, 花格周期, 方块)
  挂落：檐下的一圈透雕花格。花格周期给 2（一格空一格）。
· horseHeadWall(x1, z1, x2, z2, 墙脚Y, 级数, 每级宽, 每级高, 方块)
  马头墙：徽派建筑的阶梯山墙，两端逐级抬高。级数 3 最常见。
· screenWall(cx, cy, cz, "x"或"z", 宽, 高, 方块, 瓦顶方块)
  影壁（照壁）：一堵墙 + 顶部出檐的小瓦顶。放在大门内外。
· paifang(cx, cy, cz, "x"或"z", 间数, 柱高, 间宽, 柱方块, 额枋方块, 顶方块)
  牌坊：间数 3 = 三间四柱（最常见）。柱 + 额枋 + 顶一次成型。
· steppedTerrace(x1, z1, x2, z2, 最低级Y, 级数, 每级高, 每级进深, 方块)
  月台踏道：一级级台阶。配 sumeruBase 就是完整台基。

【★★地域流派构件签名（上面的路由选中流派后，用下面这些函数）】
★ 这批是**民居/地域**语汇，和上面官式那批（chineseRoof/dougong/sumeruBase）
  是两套语言。混用就是"哪儿都像故宫"的根源。

· guanyinDou(x1, z1, x2, z2, 墙脚Y, 墙高, 弧顶额外抬高, block)
  江南观音兜山墙：墙顶是**连续圆弧**，中间最高、两端落到檐口。
  弧顶额外抬高给 3~6；给 0 = 平墙（那就没意义了）。
  ★ 与 horseHeadWall 的区别是判据级的：观音兜连续弧（中间高），马头墙阶梯（两端高）。
· riverSteps(cx, cz, 水面Y, 宽, 级数, "x"或"z", block, 水block)
  江南河埠头：一级级下到水里的石阶。axis 是**入水方向**（"x" = 往 +X 走）。
  级数 3~6；水block 给 "water" 会在最后一级外侧铺一格水。
· meirenKao(x1, z1, x2, z2, 座面Y, 靠背侧, block)

【★官式殿宇套路（**只有玩家要宫殿 / 寺庙 / 大殿 / 衙门时才用**）】
★ 这不是"中式"的默认做法。玩家只说「中式建筑」时，请先回到上面的
  「中式流派路由」判断流派；民居一律不走这一段（走它就会变成缩小版故宫）。
1) steppedTerrace 出台阶 → 2) sumeruBase 铺台基 → 3) railing 围一圈
→ 4) 墙 + moonGate 开门洞 + windowUnit 开窗 → 5) colonnade 立柱
→ 6) 每根柱顶 dougong + sparrowBracket → 7) **chineseRoof 出整片屋顶**
  （殿宇用「歇山」、最高等级用「庑殿」、宫殿正殿用「重檐庑殿」；瓦垄与正脊自带）
→ 8) 想要更翘的角再加一层 flyingEave（贴合檐口同一 Y）
→ 9) 正脊两端想要鸱吻再加 ridgeBeasts → 10) 室内 caissonCeiling + hangingLattice

【★故宫式宫殿套路（**只有玩家明确说"故宫/紫禁城/皇宫/太和殿"才用这一段**）】
★ 这是最高等级形制，不是"中式通用做法"。单独说「建个中式房子」「建个古镇」
  时用它，出来的就是"哪儿都像故宫"——那是错的。
a. 台基：steppedTerrace（三层汉白玉台阶）+ sumeruBase（汉白玉）+ railing（望柱）
b. 墙身：朱红（red_concrete / red_terracotta），檐下横一道金线（gold_block）
c. 柱列：colonnade + 每柱顶 dougong（层数 2~3）
d. 屋顶：**chineseRoof(..., 檐口Y, 高, "重檐庑殿", yellow_glazed_terracotta,
   deepslate_tiles)** —— 太和殿、乾清宫这种正殿必须重檐；配殿/廊庑用「歇山」单檐
e. 颜色纪律：屋顶**只有**黄琉璃（黄=皇室），墙朱红，台基汉白玉，脊/勾边深色；
   不要给宫殿配青瓦或石砖屋顶（那是民居/庙宇）
f. 体量纪律：正殿的屋顶进深要比墙身**每边外挑 2~4 格**（出檐），否则像平顶盒子
g. ★★三段比例（宫殿像不像，八成看这个）：设柱高 H（墙身从台基到檐口的格数），
   · 台基高 ≈ H/3，且**至少 3 格**（三层台阶各 1 格 + 须弥座）
   · 墙身（含额枋、斗拱）= H
   · 屋顶高 ≈ 0.8H ~ 1.2H —— 屋顶比墙身矮，就立刻变成"棚子"，
     这是 AI 建宫殿最常见的塌陷：宁可屋顶高一点，也不要平。
h. ★院落层次：正殿 1 座 + 配殿 2 座 + 廊庑 2 条（用「悬山」小体量、同一黄琉璃），
   围成院子；只建一座大殿 + 一圈墙 = 庙，不是宫。
