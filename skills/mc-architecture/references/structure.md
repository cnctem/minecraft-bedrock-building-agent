# 承重体系详解(结构力学 → 方块)

配套 `SKILL.md` §2。游戏不真算力学, 但**玩家用眼睛判断"稳不稳"**。结构的关键是**可见的逻辑**:
力有去处、支撑能对齐、跨度有交代。下面每个体系给: 为什么稳 / MC 怎么搭 / 跨度与比例。

坐标约定: `y` 上, `+Z` 南, `+X` 东; 楼梯 `weirdo_direction` **0东 1西 2南 3北**, 指高(完整)那一侧;
`upside_down_bit=true` 为倒置楼梯。柱子用 `pillar_axis="y"`(原木/石英柱默认 y)。

---

## 1. 梁柱体系 (post-and-lintel)

**最基础**。竖的柱承受压力, 横的梁把楼面/屋顶重量传给柱。跨度＝梁的长度, **柱距越大梁越"险"**。

```
   ▔▔▔▔▔▔▔▔▔▔▔       ← 楣梁/额枋(architrave), 横跨
   █         █       ← 柱身(shaft)
  ███       ███      ← 柱础(base)
```
- 搭法: 柱 = `quartz_block["chisel_type"="lines"]`/`oak_log`/`polished_deepslate` 一列 `pillar_axis="y"`; 柱头用更宽的台阶/整块;
  柱顶横梁用同材质或石梁 `stonebrick`/`<木>_planks`, 出挑 1 格。
- **柱距建议**: 细高柱 2~3 格; 一般 3~5 格; 5 格以上要在柱头加**托/(bracket)**暗示承重, 或改拱。
- 柱高:柱径 ≈ **7~10**:1(古典)。柱径 1 格 → 柱高 7~10 格才显挺拔; 矮胖柱用它做墩。
- 常见错误: 柱顶没梁直接放屋顶; 柱距过大中间无梁 → "玻璃房"感。

## 2. 拱券 (arch)

**把跨度和荷载转成斜向推力**。同样跨度, 拱比梁能做得更大、更有空间感。分类:

| 类型 | 特征 | 用在哪 |
|---|---|---|
| 半圆券 | 正半圆, 罗马式 | 城堡门、罗马、罗马式教堂 |
| 尖券 | 两弧交于尖顶 | **哥特**, 显高 |
| 平券/过梁券 | 顶部近直 | 门窗过梁、现代 |
| 马蹄券 | 过半圆的收口 | 摩尔/伊斯兰 |
| 多心券/失称券 | 多段弧 | 巴洛克 |

**半圆券(开间 7, 半径 3, 起拱线 y=0)** 的拱圈剖面:
```
y=3:  █ █ █        x=-1,0,1
y=2:  █     █      x=-2,2
y=1:
y=0:  █     █      x=-3,3   ← 起拱点(springing)
     -3-2-1 0 1 2 3
```
- **拱圈(voussoir)** 用整块 + 楼梯拼圆(见 `mc-shapes`): 下方用楼梯 `weirdo_direction` 顺曲线, 让内弧顺滑;
  顶部**拱心石(keystone)** 换一种醒目方块, 正中放大。
- **起拱线**要落在**柱头/墩脚**上, 起拱点下方是实心柱墩(`stonebrick` 叠)。
- **拱肩(spandrel)**(拱与上方横墙之间的三角)用墙体填实, 或做小装饰龛。
- **尖券**: 以对侧起拱点为圆心的两段弧相交于尖顶; MC 里用楼梯逐级收, 顶部收成 1 格尖。
- 拱的**厚度/券脚**: 拱圈下方靠墙处加一圈台阶/方块做券脚, 显厚实。
- 常见错误: 拱悬空(没有起拱点)、拱圈用整块但内弧不修 → 方块感重。

## 3. 穹顶 / 拱顶 (vault & dome)

- **筒拱(barrel vault)**: 横截面是半圆, 沿房间长度**整段复制**。做法: 在 `mc-shapes` 里画一个竖直半圆剖面,
  然后用 `clone` 或逐段 `fill` 沿轴拉长。适合走廊、地窖、地铁。
- **交叉拱(groin vault)**: 两个筒拱十字相交, 交线用楼梯/半砖收成斜脊。教堂、回廊。
- **肋骨拱(rib vault)**: 交叉拱的骨架线(肋)用对比色凸显, 肋间填浅色板 → 哥特感。肋用楼梯逐级。
- **帆拱(pendentive)**: 方形基座 → 圆形穹顶的过渡。做法: 方形墙顶四角, 各用**层层出挑的托座**
  把方"补"成圆, 再在上面起穹顶(结合 `mc-shapes` 球面)。拜占庭/东正。
- **穹顶(dome)**: 用 `mc-shapes` §3 逐层半径表画半球; 顶部**采光亭(lantern)** 收口; 外部可加肋/铜皮。

## 4. 飞扶壁 / 扶壁 / 壁柱

**哥特高耸的秘诀**: 拱顶的**侧推力**靠外部扶壁顶回去。
```
        墙
        █|          ← 主墙 + 高侧窗
        █|░░        ← 跨空的"飞券"(flying arch): 用楼梯拼斜拱
   █████|          ← 外扶壁(pier) + 尖顶小塔(pinnacle, 压重)
   █████
```
- **飞券**: 从主墙高处斜向外下落一段**斜拱**, 用楼梯拼(逐格下降); 落点在外扶壁柱顶。
- **扶壁(pier)**: 外墙外的加厚竖向柱墩, 顶部加**小尖塔(pinnacle)**。
- **壁柱(pilaster)**: 贴在墙上的"半凸"柱子, 只做竖线不承重。给素墙分节奏, 也给"厚墙"错觉。
- 常见错误: 飞券只搭一半悬空; 扶壁没落地。

## 5. 桁架 (truss)

**大跨度无内柱**的屋架/厂房/谷仓。用三角形把弯矩转成杆件的拉压。
```
  ▲          ▲          王柱桁架
  █▔▔▔▔▔▔▔▔▔█         斜杆(W形)互相拉结
  █  ╲   ╱  █
  █   ╲ ╱   █
  ███████████          下弦(拉杆)
```
- 搭法: 上弦(斜梁)= 楼梯/原木; 腹杆 **W 形**用栅栏/`iron_bars`/`<木>_fence` 细杆; 下弦用横梁。
  节点用整块/台阶加厚。谷仓红棕木 + 石基。
- 现代门式刚架: 工字钢感 → `*_concrete`/`polished_deepslate` 做刚劲的直角框架 + 玻璃。
- 常见错误: 桁架没有三角形、全是横竖 → 不像桁架像栅栏。

## 6. 框架结构 / 半木结构 (half-timbered)

**骨架外露 + 填充墙**。都铎/中世纪民居、现代钢框。
```
  ██▔▔▔▔██▔▔▔▔██      外露木骨架(柱+横梁+斜撑)
  ██    ██    ██
  ██╲   ██   ╱██      斜撑(斜杠)是灵魂
  ██▔▔▔▔██▔▔▔▔██
```
- 搭法: 木骨架(`dark_oak_log`/`<木>_planks`)凸出, 其间填白(`white_concrete`/`white_wool`/白陶瓦)。
  柱、横梁、**斜撑(45° 楼梯/斜排方块)**、底层可开敞。
- 现代框架: 柱梁用灰混凝土/铁件, 填充整片玻璃幕墙。
- 常见错误: 只有横竖没有斜撑; 骨架和填充一个色, 分不出来。

## 7. 承重墙体系 (load-bearing wall)

石/砖砌体墙直接承重, 墙上开窗。**难点是"墙看起来够厚够稳"**:
- **加厚假象**: 窗**内凹** 1 格; 加**壁柱**; 四角做**转角石(quoins)**(对比色方块交错砌, 见 `facade.md`)。
- **收分(batter)**: 墙从下到上**每几层收进 1 格**(塔楼、城墙、护坡)。用 `fill` 分层渐收。
- **扶壁**: 每隔一段在外侧加竖向柱墩。
- 城堡垛口: 墙顶**间隔**留 1 格, 垛(merlon)后用通道; 箭窗用竖长窄口。
- 常见错误: 一整片平板墙 → 靠壁柱/凹窗/转角石/线脚救。

## 8. 悬挑 / 托座 (cantilever & corbel)

上层出挑、阳台、凸窗、屋檐——**必须有"托"**才不显得违反重力。
```
  ██████████      ← 出挑的楼板/阳台
   ████████       ← 每上一层多出 1 格
    ██████        ← 层层挑出的托座(corbel)
     ████         ← 每级可用 "倒置楼梯" 做斜面牛腿
      ██
```
- **层层出挑**: 用楼梯(`upside_down_bit=true`)/台阶, 每层向外多 1 格, 3~4 层内完成大部分出挑。
- **斜撑/牛腿**: 出挑下方斜向支撑(楼梯或斜排方块)。
- 现代大悬挑: 用**悬挑梁**(上宽下窄的混凝土/深板岩梁)从主体伸出。
- 常见错误: 悬挑下面空着无托 → "漂浮"。

## 9. 古典柱式 (orders) 与细部

柱 = **柱础 + 柱身 + 柱头** 三段; 柱高≈**柱径的 7~10 倍**(多立克 7、爱奥尼 9、科林斯 10)。
- 柱础: 比柱身宽 1 格的台阶/整块。
- 柱身: `quartz_block["chisel_type"="lines"]`/`*_log`, 可加**凹槽**(fluting: 柱面留竖线 —— MC 里靠相邻不同色柱子近似)。
- 柱头: 多立克=简洁圆盘; 爱奥尼=**涡卷**(两个小方块/台阶对称); 科林斯=**毛茛叶**(层层出挑的小叶 + 卷)。
- 柱顶楣梁 → 檐部(额枋/饰带/檐口)三层, 山花(pediment)三角。

## 10. 束柱 / 斗拱 / 挑檐

- **束柱(cluster pier)**: 哥特多根细柱捆一束。MC: 3×3 的柱子中心 + 四角各一根细柱, 顶部汇入肋拱。
- **斗拱(dougong, 中式)**: 柱顶一层层向外出挑的托块, 承屋檐。MC: 用楼梯/台阶**层层向外挑出**
  (每层出挑 1 格, 2~4 层), 上面放大屋顶。是中式屋顶"飞起来"的关键。
- **挑檐(eaves)**: 屋顶伸出墙面 1~2 格, 下方加一排**椽(rafter)**(倒楼梯/原木横排)和滴水。

## 11. 台基 / 基础 / 勒脚

建筑要"长在地上": 底部一圈**台基**, 比墙外扩 1 格、高出地面 1~2 格, 用深色重石。
- 台阶(stoops)接主入口; 台基四角可做转角石。
- 勒脚(plinth): 墙脚一圈略深的方块, 抗脏也分层。
- 常见错误: 墙直接插进地里, 没有台基过渡 → 建筑"没扎根"。

---

## 结构选型速记

- 想要**庄重/宏大** → 梁柱 + 台基 + 三段式 + 对称。
- 想要**高耸向上** → 尖券 + 束柱 + 飞扶壁 + 尖塔。
- 想要**大空间** → 拱/穹顶/桁架(无内柱)。
- 想要**通透现代** → 框架 + 幕墙 + 悬挑 + 平顶。
- 想要**乡土温暖** → 半木骨架 + 填充 + 大坡顶。
- 想要**厚重防御** → 承重厚墙 + 扶壁 + 垛口 + 收分。
- 无论哪种: **柱落地、梁搭柱、拱起拱、挑有托、墙有厚**。
