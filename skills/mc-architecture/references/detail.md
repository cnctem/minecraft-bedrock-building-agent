# 专家强化：深度、渐变、做旧与风格配方

配套 `SKILL.md` §3~§5。内容来自 Grian、BdoubleO100、fWhip、GeminiTay、TrixyBlox、MythicalSausage 等公开教程/访谈与社区建筑指南的提炼；数字属于**社区惯例**，最终以实机观感与 Bedrock `find_items` 为准。

## 1. 可执行总顺序

`简单形体 → 体块穿插 → 墙面深度 → 调色板/渐变 → 结构细节 → 生活化细节`

- 大工程先按 16×16 或 32×32 分区，先搭框架柱网，再逐区填墙。
- 每个立面都要有窗、结构线或材质变化；纯平墙最长 7 格，每 4~6 格至少一处凹凸。
- 一眼要有一个视觉焦点：门廊、转角塔、山墙、烟囱或翼楼。地标要高于周围建筑，村镇天际线按 3~5~4 格高度错落。

## 2. 深度(Depth)

- 标准墙 = 主体层 + 内凹 1 格 + 外凸 1 格。远景看不见 1 格凹凸时，体块穿插差要提到 ≥2 格。
- 外凸：角柱 `log/stripped_log`、门窗套 `stairs + trapdoor`、横梁、烟囱外凸 1~2 格、窗台 slab 外挑 1 格。
- 内凹：玻璃退墙 1 格，四周窗套；壁龛内收 1 格放花盆/灯笼；入口做门廊。
- 屋顶是第五立面：至少加入两个轮廓变化，如老虎窗 + 屋脊端饰、烟囱 + 小塔、两段不同坡度。
- 大建筑做"减法"：大面积保持纯色，细节集中到入口、转角、檐口三个视觉带。

## 3. 材质与渐变

- 调色板：主色 1 + 辅助 2~3，总数 ≤4；主材 ≥70%，辅材 15%~30%。
- 单墙流程：选 3~4 档同族方块 → 每 3~5 格分段 → 交界 dithering 2~3 格 → 基座 2 层最暗 → 最后撒 ≤10% cracked/mossy。
- Dithering 比例：50:50 → 70:30 → 100:0，用棋盘或随机散布，不用直线分界。
- 参考配方：
  - 石墙：`deepslate` 35 / `cobbled_deepslate` 30 / `stone` 20 / `andesite` 15。
  - 通用石链：`stone` → `andesite` → `tuff` → `cobblestone` → `mossy_cobblestone` → `stonebrick` → `stonebrick["stone_brick_type"="cracked"]` → `deepslate` → `cobbled_deepslate` → `blackstone`。
  - 暖木链：`oak_planks` → `spruce_planks` → `stripped_spruce_log` → `dark_oak_planks` → `dark_oak_log`。
- 明度按高度变化：顶部浅、基座深；木屋墙脚至少用 1 格石基，防"木材插地"。

## 4. 做旧与生活化

- 藤蔓种在石墙底部/背阴面，每 3~5 格 1 处，向上 2~4 格；屋檐、墙角和井边加密，禁止满铺。
- `stonebrick["stone_brick_type"="cracked"]` / `cracked_deepslate_bricks` 放在基座、门洞两侧、墙角，占比 ≤10%。
- `mossy_cobblestone` / `stonebrick["stone_brick_type"="mossy"]` 集中在地面接触带、屋脊背阴侧、台阶踏面。
- 门口放 1~2 个 `barrel`、`composter`、`hay_block`；墙根放 `flower_pot` 与小灌木。
- 小径用 `grass_path + gravel + dirt["dirt_type"="coarse"]` 不规则混铺，宽 2~3 格并保留毛边。
- Grian 式细节：原木堆上横放铁轨 = 货物；石按钮散在池边 = 碎石；压力板 + 花盆 = 餐盘；烟囱上下各放营火 = 长烟柱；讲台 + 活板门 = 书桌。

## 5. 分风格配方

### 中世纪 / 乡村
- 地基 1~2 层 `cobblestone` / `stonebrick`；墙身 `oak_log` 角柱 + `spruce_planks` 填充，柱距 4~8 格。
- 屋顶用 `spruce` / `dark_oak` 楼梯，坡度陡；二层每边外挑 1 格，底边用 `dark_oak_slab` / 活板门收口。
- 平面优先 L/T 形，门户可偏离中轴 1~2 格；配套铁匠铺、马厩、面包房、酒馆、瞭望塔。

### 都铎半木
- `white_concrete` / `white_wool` 填充 + `dark_oak_log` / `spruce_log` 框架。
- 竖柱间距 4~5 格；柱间顶部加斜撑，窗上做人字或菱形桁架；楼层间一圈横木带。
- 屋顶深灰/棕色陡山墙，基座用 `cobblestone`。

### 哥特
- `deepslate` / `blackstone` / `stonebrick` 主材，基座加深 3 层以上。
- 门窗为尖拱，窗宽 1~2、高 5~7，玻璃退 1 格；每 2~3 格一根凸出壁柱直通檐口。
- 玫瑰窗用彩色玻璃呈放射图案；飞券从高墙斜落到外扶壁，扶壁顶加小尖塔。

### 日式 / 中式
- 日式：白墙/方解石 + `dark_oak` 柱与格栅；檐口楼梯 + 半砖双层外挑 2~3 格，檐角上翘 1 格。
- 天守阁：石基 ≥5 层，3~5 层逐层收 2~3 格，顶层小窗与悬鱼。
- 中式：红混凝土/红陶瓦墙柱 + 深色木梁架；金黄屋顶；斗拱层用 slab/stairs 多层外挑，屋脊端头翘起。

### 现代 / 蒸汽朋克 / 奇幻
- 现代：白/灰/黑混凝土 + 石英 + 玻璃；2~3 个错位盒子，悬挑 ≥2 格，平屋顶边缘外挑 1 格。
- 蒸汽朋克：铜块混四种氧化度 + 深板岩/灰混凝土；管道外露 1~2 格，烟囱用营火冒烟，齿轮用楼梯+半砖拼圆。
- 奇幻：深青暗色屋顶 + 亮色墙 + 有机曲线；叶片间藏 `glowstone` / `sea_lantern`，屋顶厚薄不均制造剪影。

## 6. 屋顶与出檐

- 三种基础坡度：满砖 1 升 1（45°）；楼梯视觉约 63°；上下半砖交替约 22.5°。
- 坡屋顶五步：① 屋脊梁定中线；② 两侧楼梯逐排上升，每排内收 1 格；③ 檐口倒置楼梯外挑；④ 屋脊 slab 压顶；⑤ 端头加脊饰/旗帜。
- 出檐 1~2 格，日式 2~3 格；最外圈 `stair + slab` 双层出挑，下面加椽或托。
- 屋顶杂色 10%~15%，如 `spruce_stairs` 混 `dark_oak_stairs` + 少量苔石。
- 老虎窗宽 3、高 2；烟囱宽 2，顶部出挑 1 格，上/下各放营火可做长烟。
- 屋顶占总高 1/3~1/2；现代平屋顶压缩到 ≤1/5，并做女儿墙/露台栏杆。

## 7. 交付前自检

- [ ] 体块 ≥2~3 个，穿插差 ≥2 格。
- [ ] 五面都处理，无"无细节背面"。
- [ ] 主色 ≥70%，总材质 ≤4；渐变 3~5 格/段并 dithering。
- [ ] 窗内凹 ≥1、窗套外凸、同层齐顶等距。
- [ ] 柱落地、梁搭柱、拱有起拱、挑有托。
- [ ] 屋顶高 ≥墙高 ×0.5（坡顶），出檐 ≥1，有屋脊/端饰。
- [ ] 夜间每 4~6 格可达光；做旧 ≤20%。
- [ ] 大工程已 `pin_region` 并用 `ptc` 分批交付。
