## 通用（未识别出具体类别）

【设计要求】
1. 先定中轴与主体，再展开附属；主体最高、细节最密。
2. 立面做分段与节奏：每 5~10 格重复一次窗 / 壁柱 / 拱 / 浮雕。
3. 材质分区 ≥3（基座 / 墙体 / 屋顶），屋顶材质必须与墙体不同。
4. 顶部必须收束（尖塔 / 穹顶 / 山花），禁止平顶收尾。
5. 代码顺序按视觉重要性：主体 → 附属 → 环境（广场/道路/围墙最后）。

【输出前自检】
1. 主体是否 100% 完整（其代码排在文件最前）？
2. 是否有 ≥3 个材质分区？
3. 是否避免了平顶收尾？
4. 是否存在单边 >40 格的实心 fill？（有就改成 hollow + 分层楼板）

## 民居 / 商铺（小体量精修）

【设计要求】
1. 体量克制但细节密集：门楣、窗框（活板门/楼梯方块）、烟囱、屋檐外挑 1 格。
2. 单栋占地 7×9 ~ 15×15、层高 3~4；不要造出一间空旷的大厅。
3. 室内必须功能分区（起居 / 卧室 / 储藏）并有照明；地面做铺装，点缀地毯。
4. 每个立面至少 2 种处理：正面门+窗、侧面连续窗、背面实墙加装饰。
5. 材质 2~3 种主色即可，木石搭配；屋顶材质必须与墙体不同。

【输出前自检】
1. 外墙四面是否闭合？门窗是否用 air **真开口**（不是只留空格）？
2. 屋顶是否逐层收分（而不是一块平板）？
3. 室内是否有照明与地面铺装？
4. 立面是否有每 5~10 格重复一次的节奏元素？

## 塔楼 / 灯塔 / 钟楼（竖向收分）

【设计要求】
1. 竖向必须收分：用 taperedCylinder 或逐层内缩；顶部必须有收束（尖顶/穹顶/塔冠）。
2. 塔身每 4~8 格做一圈挑檐或腰线（crownMolding / frame），形成明确分段。
3. 塔内必须有螺旋楼梯（spiral / staircase）保证逐层可达。
4. 顶部设观景层：向外挑出 1 格 + 栏杆或垛口。
5. 灯塔类顶部必须有发光体（sea_lantern / lantern），且在地面视角可见。

【输出前自检】
1. 是否逐段收分，而不是一根上下等粗的柱子？（★本项目预览会抓「等截面柱」）
2. 顶部是否有收束，而不是平顶截断？
3. 塔内是否有可通行的楼梯？
4. 腰线/挑檐是否按 4~8 格规律重复？

## 城堡 / 要塞 / 城墙（防御体系）

【设计要求】
1. 四角必须有塔（prism 或 tower），且角塔要高于城墙，形成制高点。
2. 城墙顶部必须有垛口（隔格交替放置），墙体厚度 ≥2 格。
3. 城门用 arch + 门楼 + 吊闸意象；城门朝向必须明确（对着主路）。
4. 主楼（keep）居中且全城最高，与城墙形成高低层次。
5. 石材质感统一，辅以深色点缀；不同构件（墙/塔/门）材质要有微差。

【输出前自检】
1. 城墙是否四面闭合、没有断口？
2. 四角塔是否齐全，且都高于城墙？
3. 城门方向是否唯一且明确？
4. 主楼是否明显高于其他所有部分？

## 地标 / 宗教 / 宫殿（强中轴大体量）

【设计要求】
1. 强中轴：先定中轴线，两侧镜像保证**严格**对称（本项目用函数/循环，不要手写两遍）。
2. 三段式立面：台基（退台 1~3 层）→ 柱廊 / 主体 → 檐部 + 屋顶。
3. 至少运用 2 种结构语言：柱廊（colonnade）、拱券（archWall）、穹顶（dome/polygonDome）、山花（gable）。
4. 顶部必须收束（尖塔 / 穹顶 / 塔冠），禁止平顶收尾。
5. 立面节奏：每 5~10 格一组窗 / 壁柱；同一栋的上、中、下三段做法必须不同。

【输出前自检】
1. 是否严格左右对称（用镜像而不是手写两遍）？
2. 是否有「台基 → 主体 → 檐部 → 顶部」的完整分层？
3. 是否用了 ≥2 种结构语言？
4. 是否有明确的制高点收束，而不是平顶？

## 聚落 / 城镇 / 建筑群（多建筑与街巷）

【设计要求】
1. 不同建筑种类 ≥4 种，且屋顶形式不能全相同（这是反单调硬红线）。
2. 先定中轴主路，建筑沿路两侧排列，**门朝路**；路网必须连通。
3. 中心设广场（ellipse / polygon + 铺装）作为视觉焦点。
4. 天际线高低错落：至少 1 座塔 / 钟楼作为制高点。
5. 原样复制不得超过 3 份；成排建筑必须逐份做变体（层数/屋顶/配色/开窗至少 2 项不同）。

【输出前自检】
1. 建筑种类是否 ≥4，屋顶形式是否不全相同？
2. 是否每栋建筑都临路、门朝路？
3. 是否有中心广场作为视觉焦点？
4. 是否存在原样复制 >3 份的阵列？
5. 路网是否连通（有没有孤立的建筑/街区）？

## 基础设施（桥 / 码头 / 道路 / 广场）

【设计要求】
1. 桥必须用 catenaryBridge / archWall 体现跨度结构感，桥面两侧必须有护栏。
2. 两端必须可达：坡道或台阶连续，绝不允许台阶断头。
3. 道路宽度保持一致（主路 3 格 / 支路 1 格），并铺设边缘石（边区材质）。
4. 码头 / 栈道沿水线延伸，桩柱要入水（不要悬空在水面上）。
5. 连续构件要有节奏：灯柱 / 栏杆柱等距排列。

【输出前自检】
1. 两端是否都接得上地面或建筑（无断头）？
2. 桥面/栈道是否有护栏或边缘石？
3. 桥墩或拱是否落在跨中位置？
4. 道路是否与建筑的门相通？

## 遗迹 / 废墟（残破但可辨识）

【设计要求】
1. 只建「残存部分」：墙高参差不齐（随机 1~4 格），保留柱础、门框、拱的残段。
2. 顶部不规则塌陷：禁止完整屋顶（最多留一条屋梁或几根椽）。
3. 地面堆积碎石（cobblestone / mossy_cobblestone），局部被植被吞噬（vine / leaves）。
4. 必须保留可辨识的原始平面轮廓，让人能「读」出原建筑是什么。
5. 材质做风化：mossy_cobblestone / cracked_stone_bricks / 少量 deepslate 混用。

【输出前自检】
1. 是否保留了可辨识的原始平面轮廓？
2. 墙高是否参差不齐（而不是一刀切平）？
3. 是否有残存的柱础 / 门框 / 拱段？
4. 是否完全没有任何完整屋顶？

## 园林 / 景观（植被与水景）

【设计要求】
1. 分主次层次：铺装园路 → 灌木（hedge / berryBush）→ 乔木 / 藤架（arbor / vine）→ 水景（fountain / pond）。
2. 园路要有明确起终点，并与建筑的门相连；用 gardenPath 带边缘石。
3. 水景居中或作为视觉焦点，配石质边缘。
4. 植物成组分布，密度随离主景距离递减；同种植物高度可做微差。
5. 布置休憩构件：outdoorBench / stoneLantern / 灯柱。

【输出前自检】
1. 园路是否与建筑门相通、走向明确？
2. 是否有多层植被（灌 / 草 / 花），而不是单一层？
3. 是否有水景或雕塑作为视觉焦点？
4. 是否避免了「整片同一种方块铺满」？

## ★★中式古建强覆盖（识别到中式请求时，与上面冲突的要求一律作废）

1. **屋顶只能这么做**：所有屋顶必须用 `chineseRoof(x1, z1, x2, z2, 檐口Y, 高度, 形制, 瓦, 脊)`：
   - 正殿 / 大殿 / 太和殿这类最高等级 → 形制 = `"重檐庑殿"`
   - 城门楼 / 天安门式 / 楼阁 → 形制 = `"重檐歇山"`
   - 配殿 / 厢房 / 廊庑 / 一般殿宇 → 形制 = `"歇山"`
   - 亭子 / 角楼 / 塔顶 → 形制 = `"攒尖"`

   **禁止**用 dome / polygonDome / cone / gable / onionDome 做中式屋顶——那会长出穹顶和尖塔；
   中式屋顶是「凹曲坡面 + 正脊 + 垂脊 + 瓦垄」，不是半球。

2. **形态必须读得出是中式**：屋顶进深要比墙身**每边外挑 2~4 格**（出檐），檐口下加斗拱
   （dougong），台基用须弥座（sumeruBase）+ 栏杆（railing）。
   ★ 四角起翘、檐口一圈深色勾边、瓦垄，`chineseRoof` **都已经自带**，不要再叠
   flyingEave / tileRidges / ridgeBeasts —— 会堆成尖刺或双层瓦。
   ★★ 比例（比形状更容易出错）：屋顶高 ≈ 进深 × 0.35~0.45 且 ≥ 柱高 × 0.8；
   屋顶比墙身还矮 = 棚子。台基高 ≈ 柱高 / 3 且 ≥ 3 格。

3. **宫殿配色**：屋顶**只用黄琉璃**（yellow_glazed_terracotta）；墙朱红（red_concrete 或
   red_terracotta）；台基汉白玉（quartz_block / smooth_quartz）；正脊垂脊压深色（deepslate_tiles）。
   青瓦（deepslate_tiles 全屋顶）只用于民居/庙宇。

4. **屋顶不是一层皮**：同一座建筑上，屋顶要能读出「两坡以上 + 一条正脊 + 四条垂脊」；
   大面积平顶、单坡顶、或屋顶与墙身同宽，都算不合格。
