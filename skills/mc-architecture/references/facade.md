# 立面 · 门窗 · 屋顶 · 装饰

配套 `SKILL.md` §3/§4。立面决定"像不像建筑", 屋顶决定"完不完整"。

坐标约定同 `structure.md`; 楼梯 `weirdo_direction` **0东 1西 2南 3北** = 高侧朝向。

---

## 1. 三段式立面

任何一面墙都按"下重、中主、上收"分三段, 立刻摆脱火柴盒:
```
  ══════════ 檐口(出挑 1~2 + 对比色线脚)      ← 帽
   ████████  墙身(主材, 占 3~5 份)             ← 身
   ██ ▓▓ ██  窗/壁柱/腰线
  ══════════ 腰线(分隔, 可用半砖/台阶一条)
   ████████  基座/勒脚(深色重石, 高 1~2)        ← 脚
```
- 比例: 基座:墙身:檐口 ≈ **1 : 3~5 : 0.5~1**。
- 三层用**不同明度**(下深上浅, 或反之), 别一个色。

## 2. 墙面处理(把素墙救活)

- **转角石(quoins)**: 建筑**四个外角**用对比色方块**交错砌**(长一块短一块), 每格换一个方向。古典/乔治式必用。
- **壁柱(pilaster)**: 贴墙凸出的半柱, 位于开间之间, 给竖线节奏。
- **腰线(string course)**: 楼层之间一条略凸的台阶/半砖, 分上下材质。
- **勒脚(plinth)**: 墙脚一圈略深的方块, 高 1, 抗"脏"也分层。
- **壁龛(niche)**: 墙上下凹 1 格放雕像/花/火把。用半砖做龛顶。
- **凹窗(recessed window)**: 窗往里凹 1 格再放玻璃, 产生阴影 → **最有效的"真实感"技巧**。
- **材质杂色(dithering)**: 大面积同色墙按 10~20% 比例混入 1~2 种近似方块(石砖里掺苔石/裂纹),
  避免"塑料板"。但别太花, 近看才有的变化即可。
- **竖向凹槽**: 柱面/墙面留竖线(相邻两列换色)增强挺拔感。

## 3. 窗户

| 类型 | 做法 | 用在哪 |
|---|---|---|
| 单窗 | 1×2 玻璃板, 内凹 1, 四周窗框 | 民居 |
| 双联/三联窗 | 两/三扇共用框, 中间竖框 | 古典、庄重 |
| 条窗(带窗) | 横跨整面的一排玻璃板 | 现代 |
| 落地窗 | 从地面到顶的玻璃 | 现代别墅 |
| 圆窗/玫瑰窗 | `mc-build` 画圆 + 十字/辐条框 | 哥特教堂 |
| 老虎窗 | 从坡屋顶凸出的小山墙窗 | 都铎/北欧 |
| 天窗 | 平屋顶/坡顶嵌玻璃 | 现代、摄影棚 |
| 凸窗/飘窗 | 窗体外凸 1 格 | 维多利亚 |

- **窗框**: 用对比色方块/楼梯/台阶围一圈, 上下加**窗台(sill, 微出挑)** 与**窗楣(lintel)**;
  古典再在窗上做**山花(pediment)**(小三角)。
- **成组与对齐**: 同一层所有窗**顶齐平、等距**, 用模数排; 成组(1/2/3 联)比均匀散点好看。
- **凹窗做法**: 把窗位那格墙先挖掉, 玻璃放在**里层**(比墙面退 1 格), 洞口四周包框。
- 常见错误: 玻璃贴平墙面(像贴纸); 窗户间距随意; 窗框缺失。

## 4. 门与入口

- 门套: 门外扩 1 圈对比色框; 大门可用**拱券**(见 `structure.md` §2)。
- 台阶(stoops): 门前 1~2 级台阶(`*_slab`/`*_stairs`), 接台基。
- 门廊(porch)/雨棚: 入口凸出一个**小体块**(柱 + 小坡顶), 让入口有仪式感。
- 双开门/大门: 宽 2~3, 上可留**亮子(transom, 横玻璃)**。
- NPC/玩家进出的实际门用 `<木>_door`; 纯装饰门可用整块+把手(按钮/拉杆)。

## 5. 阳台 / 露台 / 栏杆

- 阳台: 出挑 1~2 格(下方有托, 见 `structure.md` §8), 栏杆用 `<木>_fence`/`iron_bars`/`<木>_wall`。
- 栏杆样式: 立柱(栅栏)+ 扶手(半砖); 间隔装饰(楼梯)。
- 露台地面换材质(深色/木), 与室内地板区分。

## 6. 线脚与檐口

- **檐口(cornice)**: 屋顶下缘一圈**向外出挑 1~2 格**的线脚, 用台阶逐层挑出(叠涩)。
- **出檐(eaves)**: 屋顶伸出墙 1~2 格; 下面加**椽(rafter)** —— 倒置楼梯或原木横排, 一排一排。
- **滴水(drip)**: 檐口最下缘加一圈台阶/半砖, 结束得干净。
- **齿饰(dentil)**: 檐下一排小方块(每隔一格), 古典味。
- **叠涩(corbel course)**: 用楼梯/台阶一层层向外挑出, 构成线脚/屋檐/斗拱(见 `structure.md` §10)。

## 7. 屋顶形式与搭法

| 形式 | 特征 | 用在哪 |
|---|---|---|
| 平顶 | 女儿墙(parapet)围一圈 | 现代、沙漠、地中海 |
| 单坡 | 单向倾斜 | 现代、附属房 |
| 双坡/人字 | 中间脊, 两端山墙 | 最通用(民居/仓库) |
| 四坡(庑殿) | 四面都坡, 无山墙 | 庄重、中式正殿 |
| 歇山 | 上段山墙 + 下段四坡 | 中式 |
| 攒尖 | 四/多面交于尖顶 | 亭、塔 |
| 复折(Mansard) | 下陡上缓两段 | 法式 |
| 穹顶 | 半球/洋葱形 | 拜占庭、巴洛克、清真寺 |

**双坡屋顶配方(45°, 建筑宽 7 = x:-3..3)** —— 每层向内收 1 格、升高 1 格:
```
# 屋檐出挑 1: 先在最外侧放层檐(楼梯, 高侧朝脊)
#   左坡(x<0) 高侧朝东(weirdo_direction=0); 右坡(x>0) 高侧朝西(=1)
fill <x0-4> <y> <z1> <x0-4> <y> <z2> <木>_stairs ["weirdo_direction"=0]   # 左檐
setblock ... ; ...                                                       # 逐层:
# y+1: x=-3,3 / y+2: x=-2,2 / y+3: x=-1,1 / y+4: 脊 x=0
setblock <x0> <y+4> <z1..z2> <木>_slab   # 屋脊(或用两块背靠背楼梯)
```
- **坡度**: 45°(每格升 1, 纯楼梯)最常见; 更陡 → 楼梯 + 整块(每格升 1~2); 更缓 → 半砖多层。
- **山墙(gable)**: 双坡两端露出的三角墙。用墙同材质填三角, 可加**半木装饰**、窗、**檐板(bargeboard)**(沿斜边的对比楼梯)。
- **屋脊装饰**: 脊上放台阶/花砖/旗帜/风向标; 中式加**正脊 + 吻兽**。
- **老虎窗(dormer)**: 在坡面上开个**小山墙凸窗** —— 先挖洞, 再搭一个迷你双坡, 正面放窗。
- **烟囱**: 竖向叠到**屋脊以上**(否则排烟不合理), 顶部做烟囱帽(台阶出挑)+ 烟(用营火+地毯/玻璃片做烟柱)。

## 8. 收口细节

- 屋顶与墙之间**必须有出檐**, 别让坡顶直接"扣"在墙上。
- 斜边用楼梯收口(避免方块锯齿); 山墙檐板压边。
- 屋角/屋脊/檐口用对比色强调轮廓线。
- 烟囱、老虎窗、天窗、通风管、旗帜、风向标 → 屋顶不空。

## 9. 做旧与纹理(点到为止)

- **杂色**: 石墙掺 10~20% 苔石/裂纹/深色, 木墙掺不同木种。
- **破损**: 局部开洞、缺块、露结构(椽/横梁), 但**承重线别破**(裂缝上仍要有支撑逻辑)。
- **植被**: 藤蔓/苔藓沿墙脚、阴面、缝隙长; 屋顶长草(苔藓/干草块)。
- **比例**: 做旧 ~10% 就够, 多了变废墟。

## 10. 配色分层(立面)

- 主材(墙) + 次材(基座/线脚) + 强调(门窗框/装饰) + 屋顶点缀色。
- 明度分层: 基座最深 → 墙身中 → 檐口/山花最浅(或反向)。
- 冷暖: 石(冷)+木(暖)是百搭组合; 全冷偏冷峻, 全暖偏田园。
- 详细配色与风格对应见 `styles.md`; 室内灯光见 `mc-interior`。
