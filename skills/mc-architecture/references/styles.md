# 风格库(结构 + 立面 + 材质)

配套 `SKILL.md` §5。每种风格按 **结构 / 体块屋顶 / 立面门窗 / 材质配色 / 起手要点** 五行给要素。
ID 以 `find_items` 为准; 命名坑见 `SKILL.md` §6。

---

## 中世纪民居 / 乡村
- 结构: 半木或石基木构; 简朴。
- 体块: 小而错落, 2~3 层, 坡顶陡, 木瓦。
- 立面: 小方窗、木质门窗、外露横梁, 一层可半开。
- 材质: `oak`/`spruce` 木 + `cobblestone`/`stonebrick` 基座 + `hay_block` 茅草顶(或深色木板)。
- 起手: 石基 + 木墙 + 陡坡茅草顶 + 烟囱 + 藤蔓。

## 都铎 / 半木 (Tudor)
- 结构: 黑白半木骨架(opentimber), 斜撑。
- 体块: 窄高、往上略出挑(jettied), 陡坡顶。
- 立面: 骨架横竖斜交错, 白灰填充, 小格玻璃窗。
- 材质: `dark_oak_log`/`dark_oak_planks` 骨 + `white_concrete`/白陶瓦 填 + 深色顶。
- 起手: 先用深木画骨架网格, 空隙填白, 角落加斜撑楼梯, 顶出挑 1 格。

## 罗马式 / 诺曼
- 结构: 厚重承重墙 + 筒拱 + 小窗(拱窗)。
- 体块: 低矮敦实、对称, 厚重。
- 立面: 半圆拱窗/拱门、壁柱、圆窗, 墙厚内凹。
- 材质: `stonebrick`/`cobblestone` 灰石 + 少量深色线脚。
- 起手: 厚墙(内凹窗)+ 半圆拱门 + 坚固塔楼。

## 哥特 (Gothic)
- 结构: **尖券 + 飞扶壁 + 束柱 + 肋骨拱**, 追求高。
- 体块: 高耸、竖向线条拉长, 双塔/尖塔。
- 立面: 尖拱门窗、**玫瑰圆窗**、束柱、飞扶壁、小尖塔(pinnacle)。
- 材质: 石(`stonebrick`/`deepslate_bricks`/`quartz`)+ 彩绘玻璃(染色玻璃)。
- 起手: 定高(层高 8+), 竖束柱, 尖券窗, 外部飞扶壁撑住, 顶部尖塔。

## 古典希腊 / 罗马
- 结构: **梁柱(柱式)**; 罗马加拱券/穹顶。
- 体块: 巨大台基 + 柱廊 + 三角山花, 严格对称。
- 立面: 柱式(多立克/爱奥尼/科林斯)、山花、额枋饰带、浮雕。
- 材质: 白(`quartz_block`/`quartz_bricks`/`calcite`/`diorite`)+ 少量金/铜点缀。
- 起手: 台基 → 排柱(柱距均匀) → 楣梁 → 山花三角; 比例严谨。

## 拜占庭 / 东正
- 结构: **帆拱 + 中央大穹顶**, 多个小穹顶簇拥。
- 体块: 集中式、穹顶统率, 方形基座。
- 立面: 半圆拱窗、马赛克墙面(彩色块)、鼓座开窗。
- 材质: 砖/石 + 金顶(金块/黄铜)+ 彩色玻璃。
- 起手: 方形石基 → 四角帆拱过渡 → 中央半球穹顶 + 采光亭。

## 中式(宫殿 / 庙宇)
- 结构: 木构架 + **斗拱** + 大坡顶 + 台基; 中轴对称、院落。
- 体块: 横向舒展, 屋顶厚重出檐, 层层台基。
- 立面: 朱红柱、格栅门窗、斗拱、彩画、飞檐翘角。
- 材质: `dark_oak`/`crimson_planks` 柱梁 + 朱红(`red_concrete`/`red_terracotta`)+ 金(`gold_block`)+ 灰瓦/绿瓦(`gray/green` 系 + `brick`?)。
- 起手: 台基 → 柱网 → 斗拱层(层层出挑)→ 歇山/庑殿大屋顶 + 正脊吻兽 + 飞檐。

## 日式
- 结构: 木构, 大屋檐, 低矮贴地。
- 体块: 低矮、水平舒展、缘侧(engawa)与庭院。
- 立面: 木格窗(障子, 用白色/纸感方块)、推拉门、深色木格。
- 材质: `spruce`/`birch`/`bamboo` + 白(`white_wool`/`white_concrete` 代纸)+ 深木梁 + 苔石。
- 起手: 低台基 + 深木柱梁 + 大出檐(斗拱感)+ 木格窗 + 苔藓庭院。

## 北欧 / 斯堪的纳维亚
- 结构: 木构, **陡坡顶**(排雪), 兼实用。
- 体块: 简洁几何, 陡顶, 高烟囱。
- 立面: 小窗、木饰面、暖色点缀。
- 材质: `spruce`/`birch` 浅木 + 白 + `light_gray` + 一点暖红/黄。
- 起手: 陡坡顶(楼梯密铺)+ 木墙 + 白窗框 + 暖光。

## 地中海 / 西班牙
- 结构: 厚白墙 + 平顶/缓坡 + 拱。
- 体块: 低矮、白墙、平屋面、露台。
- 立面: 圆拱门廊、木格栅、爬藤、蓝/赭色点缀。
- 材质: `calcite`/白混凝土 + `terracotta`/`red_sandstone` 瓦 + 木 + 蓝(`blue_terracotta`)。
- 起手: 白厚墙(内凹拱窗)+ 平顶女儿墙 + 露台 + 陶瓦檐。

## 文艺复兴 / 巴洛克
- 结构: 承重墙 + 柱式 + 穹顶。
- 体块: 严格对称、穹顶统率、立面分段。
- 立面: 柱式、山花、线脚繁复、涡卷、浮雕。
- 材质: 石/石英 + 金/铜点缀。
- 起手: 对称立面(柱式 + 山花)+ 中央穹顶 + 丰富线脚。

## 维多利亚 / 乔治式
- 结构: 砖/石承重 + 木构装饰。
- 体块: 多层、凸窗、复杂屋顶(多坡 + 老虎窗)。
- 立面: **凸窗(bay window)**、转角石、齿饰檐口、彩绘。
- 材质: `brick_block`/石 + `dark_oak` 木 + 深色顶 + 暖色。
- 起手: 多层砖体 + 凸窗阵列 + 转角石 + 齿饰檐 + 多坡顶老虎窗。

## 现代 / 极简
- 结构: **框架 + 玻璃幕墙 + 悬挑**。
- 体块: 几何体块穿插、咬合、错动; 平顶。
- 立面: 大玻璃、横向条窗、素面、少装饰。
- 材质: `white_concrete`/`light_gray`/`gray_concrete` + `glass_pane` + 木/铜点缀 + `polished_deepslate`。
- 起手: 大几何体块咬合 → 开大玻璃 → 平顶女儿墙 → 一两个悬挑/穿插体。

## 工业 / Loft
- 结构: 砖墙 + **钢桁架** + 大钢窗。
- 体块: 方正大块, 大跨无内柱。
- 立面: 红砖 + 黑钢窗格 + 暴露管线/漏斗 + 烟囱。
- 材质: `brick_block`/`deepslate` + `iron_bars`/`copper`/`polished_deepslate` + `gray_concrete`。
- 起手: 砖体 + 大片钢窗格(铁栏杆分格)+ 屋顶桁架外露 + 管道。

## 蒸汽朋克
- 结构: 金属框架 + 桁架 + 管道 + 齿轮(用铜格栅/活板门)。
- 体块: 机械感、圆角金属、烟囱、仪表。
- 立面: 铜(4 种氧化度)层叠、铜格栅、红石灯、压力表(`target`/`observer` 装饰)。
- 材质: `copper_block`/`cut_copper`/`oxidized_copper`/`copper_grate` + `deepslate` + `redstone_lamp`/`copper_bulb`。
- 起手: 深色木/铁框架 + 铜板包面(深浅氧化混搭)+ 格栅与管道 + 暖灯。

## 沙漠 / 摩尔 / 中东
- 结构: 土坯承重墙 + 穹顶 + 拱, 厚墙小窗。
- 体块: 立方体 + 洋葱穹顶 + 庭院; 风塔。
- 立面: **马蹄券**、几何镂空(格栅)、平顶女儿墙。
- 材质: `sandstone`/`red_sandstone`/`mud_bricks`/`terracotta` + 蓝绿琉璃点缀。
- 起手: 沙色厚墙 + 马蹄拱门 + 洋葱穹顶 + 木格栅窗。

## 幻想 / 精灵 / 有机
- 结构: **有机曲线**(见 `mc-shapes`), 与自然融合。
- 体块: 弧线、悬空、嵌入巨树/山体。
- 立面: 拱形门窗、藤蔓、发光菌/萤石、藤桥。
- 材质: 木 + 苔藓 + 发光方块 + 水 + 硬化的弯曲体。
- 起手: 先做**流畅曲面壳体**(球/筒/有机), 再嵌木质门窗, 大量植被与发光。

## 快速选择

- 要**温暖宜居** → 中世纪民居 / 北欧 / 地中海。
- 要**庄严宏伟** → 古典 / 哥特 / 中式宫殿 / 文艺复兴。
- 要**阴森神秘** → 哥特 / 废墟 / 拜占庭(暗调)。
- 要**未来干净** → 现代 / 工业。
- 要**厚重奇幻** → 城堡 / 蒸汽朋克 / 精灵。
- 拿不准: **石基 + 木身 + 坡顶 + 三段式立面** 是万金油。

> 风格统一最重要: 一片区域别混三种风格。玩家要"中世纪村庄"就所有房子共用同一套材质与屋顶语言。
