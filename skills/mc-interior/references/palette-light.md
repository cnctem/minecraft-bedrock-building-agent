# 配色与灯光

配套 `SKILL.md`。好看的房间 = **克制配色 + 层次灯光**。

## 1. 配色法则

- **60/30/10**: 主色 60%(墙/地)、次色 30%(家具/大面)、强调色 10%(软装/点睛)。
- **材质 ≤ 4~5 种**: 木 + 石 + 一点金属/玻璃 + 1~2 个强调色。超了就乱。
- **先定冷暖**: 暖(木+黄光)温馨, 冷(石+白光)现代/清冷。全屋统一, 局部可对比。
- **明暗层级**: 墙浅、地中、家具深(或反过来), 别全是一个明度。
- **对比两种做法**: 邻近色(和谐, 如棕/米/白)或互补色(活泼, 如蓝+橙, 绿+红)。新手先邻近色。

### 常用材质色卡

| 类别 | 偏浅 | 中间 | 偏深 | 强调 |
|---|---|---|---|---|
| 木材 | birch / oak / cherry | acacia / mangrove | spruce / dark_oak / jungle | crimson / warped |
| 石材 | 石英 quartz / calcite / diorite | stone / andesite / tuff | deepslate / blackstone | — |
| 硬表面 | white / light_gray 混凝土 | gray 混凝土 / 陶瓦 | black 混凝土 | 任意亮色混凝土 |
| 柔软 | white 羊毛/地毯 | light_gray / gray | black | 任意色羊毛 |
| 金属 | 铁块/铁栏杆 | 铜(风化) | 深板岩 | 金块 / 涂蜡铜 / 红石灯 |
| 玻璃 | 玻璃板 | 灰色染色玻璃 | 黑/深色玻璃 | 淡蓝/彩色 |

### 风格速配

- **温馨乡村**: oak/spruce + 石砖 + 白 + 绿植 + 暖光。藤蔓/苔藓做旧。
- **现代简约**: 白混凝土 + light_gray + dark_oak + 玻璃 + 铜 + 隐形光。(注意别太空)
- **北欧**: birch + 白 + 浅灰 + 原木 + 绿 + 暖白灯。
- **中世纪**: dark_oak/spruce + 石砖/圆石 + 深色地毯 + 火把/营火 + 铁件。
- **日式/禅**: 樱花木/竹子 + 白 + 深木横梁 + 苔藓/竹 + 纸灯笼(白)。低矮家具。
- **蒸汽朋克**: 铜(4 种氧化度) + 深色木 + 铁 + 红石灯 + 铜格栅 + 管道。
- **工业 loft**: 灰混凝土 + 铁 + 玻璃 + 暴露管线(漏斗/铁栏杆) + 红石灯。
- **奢华**: 石英 + 金块 + dark_oak + 红/紫地毯 + 吊灯 + 画。

## 2. 灯光

### 光源速查(亮度 / 色温)

| 方块 | 亮度 | 色调 |
|---|---|---|
| 火把 torch | 14 | 暖橙 |
| 灯笼 lantern / 营火 campfire | 15 | 暖橙 |
| 蜡烛 candle(可叠 4) | 12 | 暖橙 |
| 荧石 glowstone / 菌光体 shroomlight | 15 | 暖白/橙 |
| 海晶灯 sea_lantern / 末地烛 end_rod | 15/14 | 冷白 |
| 灵魂火把/灵魂灯笼 soul_* | 10 | 冷蓝 |
| 蛙明灯 froglight | 15 | 赭黄暖/青翠绿/珠光粉紫 |
| 铜灯泡 copper_bulb | 15 | 暖白(可红石控制) |
| 红石灯 redstone_lamp | 15 | 暖白(需通电) |
| 光源方块 light_block | 0–15 | **完全隐形**, 状态 `block_light_level` |

### 三条原则

1. **基础光无死角**: 先均匀铺一层隐藏光(间距约 5~6 格), 保证没有黑角落。
2. **主灯定基调**: 房间中心/桌面上方一个吊灯, 决定风格与色温。
3. **强调光照焦点**: 画、壁炉、展柜、绿植用小灯/蜡烛单独打亮, 把视线引过去。

### 隐藏光(必学)

- 地板下/墙里/天花板埋 `glowstone` / `shroomlight` / `sea_lantern`,
  上面盖 **`*_carpet`(透光)** 或半砖/活板门 —— 光出来但看不见光源。地毯不挡光, 最好用。
- 吊顶下沉 1 格, 藏 `light_block ["block_light_level"=15]` 或荧石, 再封板。
- 门后、楼梯下、家具背面这些死角单独补。

### 灯具造型

- **吊灯**: 天花板 → `chain`(1~3 格) → `lantern`; 或 `end_rod` 中心 + 四角 `lantern`。
- **壁灯/落地灯**: 墙上 `torch` / 挂在方块下的 `lantern`; 落地灯 = `fence` 杆 + `end_rod`/`lantern`。
- **灯罩**: 用 `*_trapdoor`、`glass_pane`、`iron_bars`、`*_slab` 罩住光源做成灯笼/罩灯。
- **烛台**: `oak_fence` + `candle ["candles"=2]` 叠多根。
- **冷暖混搭**: 主光暖(灯笼), 局部冷(灵魂灯/海晶灯)做对比, 氛围立刻高级。

### 避免

- 满地火把 —— 用隐藏光或灯具造型替代。
- 光照绝对均匀 —— 留一点明暗对比才有层次。
- 强光正对床/沙发 —— 刺眼; 用柔和的蜡烛/灯笼。
- 忘了开灯源状态 —— `candle`/`campfire`/`copper_bulb` 有 `lit` 类状态, 放完 `get_block` 确认已亮。
