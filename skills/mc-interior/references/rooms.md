# 房间清单(能做什么)

配套 `SKILL.md`。拿到"装修一下"先在这里对号入座, 照清单配齐再个性化。
尺寸是**建议下限**; 小于它做"紧凑版"(减少件数、多用壁挂), 大于它再做多分区。
摆法/命令见 `furniture.md`。

> 通用布局口诀: **进门先留 2 格动线 → 最大件靠主墙 → 主墙对面放视觉重心(壁炉/窗/画) →
> 中间放地台或地毯分区 → 角落补杂物 → 最后打光。**

---

## 玄关 / 门厅(2×3 起)
- 必配: 鞋柜(`barrel`/`chest` 整排)、挂衣架(`armor_stand` 或墙上 `fence`)、
  换鞋凳(`oak_slab`+`oak_fence`)、`<色>_carpet` 地垫、一盏壁灯。
- 加分: 墙上 `frame` 挂钥匙/地图、`flower_pot`、门牌 `sign`。
- 要点: 别堵门; 灯光偏暖, 一进门有"到家"感。

## 客厅(7×7 起)
- 必配: 沙发(3 座)+ 茶几 + 地毯 + 主灯/落地灯; 一面视觉墙。
- 加分: 壁炉、书架墙、电视墙(`black_concrete`+`glass_pane`)、植物、挂画、唱片机。
- 要点: 沙发面朝视觉墙, 中间铺地毯圈出"会话区"; 层高 ≥5 才放吊灯。
- 小户型: 沙发贴墙 + 小茶几 + 墙上挂画即可, 别硬塞。

## 卧室(5×5 起)
- 必配: 床(居中或靠主墙)、两个床头柜 + 灯、衣柜、地毯。
- 加分: 床头板、窗帘(`wall_banner`)、梳妆台(`crafting_table`+镜子)、画、植物、书架。
- 要点: 床两侧留 ≥1 格; 灯光柔(蜡烛/灯笼), 避免正对床顶的强光。

## 餐厅(6×6 起)
- 必配: 餐桌(长桌 5~7 格)、椅子按人数、餐灯(桌上吊灯)、餐边柜。
- 加分: 桌上摆件(蛋糕/花/蜡烛)、墙上画、地毯、酒架(`iron_bars`+`frame`)。
- 要点: 桌子与墙留 ≥1 格拉椅空间; 吊灯正对桌心。

## 厨房(5×5 起)
- 必配: L 形或一字台面、水槽(`cauldron`)、灶(`smoker`/`campfire`)、冰箱(`iron_block`+`iron_door`)、上柜。
- 加分: 中岛台、吧台椅、挂锅架(`chain`+`anvil`/`cauldron`)、货架、垃圾桶(`cauldron`)。
- 要点: 水槽—灶—冰箱三点成三角形最顺手; 台面连续别断开。

## 书房 / 办公室(5×5 起)
- 必配: 书桌 + 椅、书架墙、台灯、地毯。
- 加分: 壁炉、globus/展示框、地图墙、绿植、单人沙发+阅读灯、梯子(`ladder`)够高处书。
- 要点: 桌子靠窗借光, 书架满墙做背景; 灯光以局部照明为主。

## 卫浴(3×3 起)
- 必配: 浴缸/淋浴、马桶、洗手台+镜子、毛巾架。
- 加分: 瓷砖墙(蓝/白陶瓦)、地垫、香薰(`candle`)、小窗、浴帘(`banner`)。
- 要点: 三件套沿墙一字排开最省地; 用蓝白配色显干净。

## 储物间 / 仓库(4×4 起)
- 必配: 箱子阵(带 `frame` 标签)、货架(`bookshelf`/`barrel` 堆叠)、工作台。
- 加分: 分类牌、`iron_bars` 笼、矿车/漏斗、天窗采光。
- 要点: 过道 ≥1 格, 箱子按类别分区并挂标签, 顶部埋灯。

## 工作间 / 工坊(5×5 起)
- 必配: 各工作站(`crafting_table`/`smithing_table`/`anvil`/`stonecutter_block`/`grindstone`/`loom`/`cartography_table`)、
  材料仓(`barrel`)、工具墙(`frame`)。
- 加分: 熔炉阵/自动炉、`hopper` 物流、铁砧台、水池(`cauldron`)、`brewing_stand`。
- 要点: 按工序动线排; 工具墙上墙, 台面留空操作。

## 儿童房 / 客房(4×4 起)
- 必配: 床/双层床、小桌、玩具箱(`chest`)、地毯。
- 加分: 彩色羊毛墙、`frame` 挂玩具、积木(`concrete` 色块)、挂旗。
- 要点: 高饱和撞色 + 低矮家具, 安全无棱角。

## 地下室 / 酒窖(任意)
- 必配: 酒架(`iron_bars`+`frame`)、木桶(`barrel`)、暖色灯。
- 加分: 拱顶(`mc-shapes` 技能)、砖石墙、火把暖光、秘密门(画后藏门)。
- 要点: 用暗色石材压重, 灯光集中一小片制造氛围。

## 阁楼 / 塔楼房间(小而不规则)
- 必配: 贴斜顶放低矮家具(地台床、矮柜)。
- 加分: 天窗、望远镜(`end_rod`+`telescope`?)装饰、环形书架。
- 要点: 顺着斜面做家具, 别留下死角; 用小地毯/灯打破局促。

---

## 给自主装修的决策顺序

1. 房间尺寸 → 对照上表选"紧凑/标准/大户型"。
2. 房间用途(玩家没说就按房间形状猜, 或默认"起居+储物")→ 取必配清单。
3. 看现有外墙/地板材质选调色板(`palette-light.md`)。
4. 家具按 `furniture.md` 配方摆, 用 `ptc` 批处理。
5. 补软装与杂物。
6. 灯光收尾, `inspect_region`(filter=light) 或 `get_block` 检查暗角。
7. 汇报 + 让玩家加需求。
