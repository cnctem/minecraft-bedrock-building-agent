# 室内装修

> 光照/藏灯/夜景单独成书, 见 `mc-lighting`。手册(内饰 / 家具 / 氛围)

内饰不是把家具沿墙摆一圈，而是按 **结构 → 分区 → 家具 → 软装 → 灯光 → 杂物** 推进。
先定视觉焦点，再把家具围着焦点成组；优先做形状，再定颜色。指令见 `mc-commands`，ID 一律用 `find_items` 确认。

## 0. 自主工作法

- 默认不追问：`get_player_position` 定位，`get_slice` 量长宽高与门窗、`inspect_region` 看现有材质；延续外墙/地板风格。没有风格时用 `oak_planks + stonebrick/deepslate + white_concrete`。
- 房间 <5×5 做紧凑型，>9×9 再分区；通道主要动线 ≥2 格，家具之间 ≥1 格。
- 先做一个角落小样，退后看；满意再铺开。每区 1~2 个视觉焦点，材质 ≤5 种，允许留白。
- 施工顺序：地板/墙裙/吊顶 → 焦点 → 大件 → 小件 → 软装 → 灯光。任一步都可停可续。

## 1. 五层与专家总纲

1. **结构**：地板、墙裙/立柱、吊顶/梁、门窗套。
2. **分区**：用地毯、吊顶变化或家具组划分，不打墙也能分区。
3. **家具**：桌椅床柜台，按既有高度和动线配。
4. **软装**：画、旗帜、植物、书、地毯、垫子。
5. **灯光**：基础光无死角 + 主灯 + 功能光 + 氛围光；每个房间至少 3 处、3 种高度。
6. **杂物**：每房至少 3 件合理小物，占家具面积 <20%，贴墙/贴桌/贴地，不堵路。

> **深度 > 颜色**：墙面至少结构层 + 填充层 + 细节层；家具先看楼梯/半砖/栅栏组成的剪影，再谈材质。

## 2. 人体尺度

| 项 | 建议 |
|---|---|
| 净高 | 3 紧凑且压抑；4~5 舒适；大厅 6+ |
| 房间下限 | 卧室 5×5；客厅 7×7；厨房 5×6；卫浴 3×4；书房 5×5 |
| 桌高 | 1.5 格(半砖)或 0.5~1 格(压力板/地毯薄面) |
| 座面 | 楼梯或半砖，约 0.5~1 格 |
| 通道 | 主通道 ≥2；桌椅后拉椅 ≥1；走廊 2~3 宽、高 ≥3 |
| 门 | 高 2、宽 1；双门 2×2 |
| 色量 | 主色 60 / 次色 30 / 强调 10；总材质 3~5 种 |

## 4. 配方库

- **整间房优先用函数**(`api.lib`, 见 **`references/functions-interior.md`**)):
  `living_room_set(cu, v, cw, facing)` 客厅、`bedroom_set` 卧室、`kitchen_counter` 厨房台面、
  `entryway_set` 玄关、`storage_nook` 储物、`shelf_run` 置物架、`clutter_corner` 杂物、
  `room_divider` 隔断、`lantern_ceiling` 吊灯阵; 小户型整套用 `cottage_interior`。
  函数一次性摆好“地毯 + 大件 + 焦点 + 灯”, 之后只做换材质和挪位置, 比逐件手摆快且不乱。
- **装饰守则与 y 语义（本手册硬规则，见技能 `mc-build` 的
  `references/mega-build-guide.md`【三】/【三·补】）**：
  窗一律用 `windowUnit`/`windowBand`（不要徒手挖洞）；屋顶完成必加 `eavesTrim`；
  墙面按上/中/下三段分别用 `wallTrim`/`crownMolding`；
  室内必备 `carpetArea` + `chandelier` 或 `fireplace`；门前 `lampPost`；
  庭院中心 `fountain` + `gardenPath`；广场四周 `statueGroup` + `planterRow`。
  装饰方块应占总量 5%~10%（小房子 15%~25%）。
  ★ `gardenPath`/`carpetArea`/`lanternCeiling` 等 7 个函数的 **y 在最后一个参数位**。
- 现有 40+ 件餐桌椅、沙发、床、柜、厨房、卫浴、壁炉、灯具做法见 **`references/furniture.md`**。
- 网上教程提炼的 60+ 件房间配方、现代电视墙、四柱床、隐藏营火壁炉、厨房三角等见 **`references/expert-rules.md`**。
- 通用映射：楼梯=座椅/靠背；半砖=桌面/台面；栅栏+压力板=小圆桌；活板门=柜门/扶手/面板；木桶=柜体；炼药锅=水盆；展示框=挂件/屏幕/把手；地毯=床品/地垫/藏灯盖；灯笼=默认灯具。

## 5. 房间与布局

各房间的必备家具、尺寸、加分项见 **`references/rooms.md`**，专家动线和密度规则见 **`references/expert-rules.md`**。

- 进门先留 2 格；第一眼对景应是壁炉/书架墙/大画/大窗。
- 最大件靠主墙，家具围焦点成组，中央不要全空也不要塞满。
- 床尾、桌背不要正对门；厨房灶-水槽-储物三点各 2~4 格。
- 开放式空间用地毯 + 吊顶变化分区；小户型用浅色主色、垂直收纳和贴墙家具。

## 6. 配色与灯光

- **60-30-10**：墙地 60%、家具 30%、软装点睛 10%；色相 ≤2 个，木+石+金属+一种强调。
- 地面：纯色木、2 格棋盘、2×2 拼花、深色边框；地毯应比区域小 1~2 格，可叠层。
- 墙面：下 1~2 格深色墙裙 + 半砖压线，上部浅色；每 3~5 格立柱或壁龛打破平墙。
- 天花板：每 3~4 格一条原木梁；同地板相比深 1 档；吊顶下沉 1 格藏灯带。
- 硬指标：敌对生物在光照 0 生成；可站方块目标 ≥7、绝对 ≥1。灯笼间距 ≤10 格、灵魂灯 ≤7 格，水每格额外衰减 3。
- 三层照明：主灯(吊灯/吸顶)、功能灯(台面/书桌/床头)、氛围灯(壁炉/展示柜/地毯下)。
- 藏灯 8 法：地毯下、半砖下、树叶中、画后、活板门后、家具背后、吊顶灯带、水景底灯。详见 **`references/palette-light.md`**。

## 7. 落地流程

1. `get_slice` 量房、`inspect_region` 读材质；`pin_region` 覆盖全房。
2. 定焦点、调色板、家具清单；先摆最大件，再补小件。
3. 落地二选一: 小改动用 `ptc` 批量提交 `setblock`；整间房/整栋用建造引擎写程序,
   直接调 `api.lib` 的成套函数(预览 → 看渲染 → 提交, 可撤销)。家具坐标仍是局部 `(u, v, w)`。
4. 摆放后抽检状态：楼梯 `weirdo_direction` 0东 1西 2南 3北，半砖 `vertical_half`，活板门方向/开合。
5. 灯光最后做：先隐藏光源消灭暗角，再装主灯；`inspect_region`/`get_block` 检查光照 ≥1。
6. 交付自检：动线、焦点、无悬空、无挡门、材质 ≤5、杂物 ≥3、光 ≥1。

## 8. 坑清单

- 层高 <3 还放吊灯；先量高度。
- 家具贴墙悬空：告示牌、活板门、台阶等需要附着面。
- 地毯放在半砖上会中空；地毯要放整块。
- 火把满墙外露；室内改灯笼/藏灯，火把只做局部。
- 家具贴墙摆一圈而中央无焦点；必须围焦点成组。
- 桌子高于床、椅子用整方块；回到 0.5~1.5 格高度体系。
- 超过 5 种材质、冷暖无过渡、满铺书架/画 → 失控，先回到 60-30-10 和留白。
- 灯距 >10 格导致暗角刷怪；交付前逐格检查。
- ID 和状态凭记忆猜：Bedrock 的 `wooden_door`、`<木>_standing_sign`、`bed` 等一律 `find_items` + `get_block`。
