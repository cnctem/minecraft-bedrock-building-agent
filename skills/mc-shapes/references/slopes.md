# 斜墙、坡度模板与大尺度曲面

配套 `SKILL.md` §5。目标是让 1 格方块被远处读成一条连续斜线。

## 1. 斜率模板

| 斜率 | 前进 1 格时抬升模板 | 视觉角 | 用途 |
|---|---:|---:|---|
| 1:1 | 抬 / 抬 / 抬 | 45° | 屋顶主坡，必须做面接触处理 |
| 1:2 | 抬 / 平 / 抬 / 平 | ≈27° | 斜墙、长坡默认 |
| 1:3 | 抬 / 平 / 平 / 抬 | ≈18° | 大屋顶、城墙上坡 |
| 2:3 | 抬 / 抬 / 平 | ≈34° | 介于 1:1 与 1:2 |
| 缓曲面 | 抬 / 平 / 抬 / 半 | 渐变 | 插半砖打破节奏 |

- 立面斜墙默认 1:2；塔身收分每 4~6 层收 1 格。
- 1:1 纯之字只有角接触，远看会断裂；必须加半砖夹层和楼梯外沿。

## 2. 45° 斜墙正确做法

- 沿之字对角线放**整砖 + 半砖交替**，使墙在两侧各退半格，形成 1 格厚的锯齿夹层。
- 序列示例：整砖 → 整砖 + 内侧上半砖 → 整砖错半格 → 整砖 + 外侧上半砖，循环。
- 外沿始终贴同材质楼梯倒角：**半砖放内侧消厚度，楼梯放外侧消角度**。
- 每 3~5 格插入一段 1 格宽的水平"喘息段"，打破无限重复的锯齿。
- 楼梯材质必须与墙同色系，否则会放大锯齿。

## 3. 大尺度曲面(R≥30)

- R≤20 查 `circle-tables.md`；R>20 用公式/Plotz 出坐标，不要心算。
- 地面每 10 格放临时参考柱，先确认中心与四极点。
- 圆周按 45° 分 8 段，每段单独闭合；接缝最容易差 1 格，必须单独校验。
- 大球体逐层半径变化平缓，可把轮廓相同的连续层成组施工，而不是每层重画。
- 大椭圆用 `x=round(Ra*sqrt(1-(z/Rb)²))` 逐行扫描，或按 45° 分段求点。

## 4. 抹平配比与自检

- 高差 ≥1 格/格：整块；0.5~1 格/格：楼梯；≤0.5 格/格：半砖。
- 8~12 格坡常见整块:楼梯:半砖 = 4:4:2 到 5:4:1，半砖收尾贴平地。
- 凸角换楼梯、凹角换半砖，楼梯朝向贴曲线切线。
- 双层壳：内层整圆，外层转折处半砖外扩半格，圆润感来自错位而非增加方块。
- 自检：45° 接缝无 1 格错位；半砖不产生斑马纹；楼梯朝向连续；终点与地面齐平。
