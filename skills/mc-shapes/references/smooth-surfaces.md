# 柔和曲面 / 平滑过渡(基岩版)

配套 `SKILL.md` §4。做圆顶、穹顶、弧形屋面、山丘、拱、圆角建筑前读这一份。

## 0. 台阶感从哪来

方块是整格立方体, 曲线是连续的, 落差只能量化成整数。两个可控杠杆:

1. **收放节奏**: 相邻两层(或相邻两列)的高度/半径差 ≤1 格。差 2 就会看到明显台阶;
   接近球顶时半径几乎不变, 那段会"发平", 需要靠楼梯/半砖在边缘过渡。
2. **半高方块**: 一格高差用半砖拆成 0.5+0.5, 视觉斜率立刻减半。楼梯本身就是 45° 的"半格+整格"组合。

**判断标准**: 站远看轮廓是不是一条顺滑的弧; 只盯着单块看永远有棱角。

## 1. 半高方块速查

| 想要 | 写法 | 说明 |
|---|---|---|
| 下半砖(占格子下半) | `stone_slab ["minecraft:vertical_half"="bottom"]` | 顶面在 y+0.5 |
| 上半砖(占格子上半) | `stone_slab ["minecraft:vertical_half"="top"]` | 顶面在 y+1.0, 常用来接上一层底面 |
| 整块 | 直接用原方块 | 或 `*_double_slab`(双半砖是独立 ID, 不是状态) |
| 正楼梯 | `stone_stairs ["weirdo_direction"=d,"upside_down_bit"=false]` | 一格内完成 0→1 的踏步 |
| 倒楼梯 | `stone_stairs ["weirdo_direction"=d,"upside_down_bit"=true]` | 挂在上一层底部, 做向内收的檐口/斜面过渡 |

- `weirdo_direction`: **0 东 1 西 2 南 3 北**, 指楼梯**完整(高)那一侧**朝向; 高侧朝向 = 上坡方向。
- 拿不准朝向就**放一块 → `get_block` 读状态 → 照抄**, 比背表可靠(见 `mc-commands/references/block-states.md`)。
- 想更细腻还有 `snow_layer`(每层 0.125 高)可做极缓坡, 但状态多、易错, 非必要不用。

## 2. 坡度配比(升:进, 即每几格升 1 格)

| 坡度 | 做法 | 备注 |
|---|---|---|
| 1:1(45°) | 纯正楼梯, 每格升 1 | 最陡又顺, 城堡墙、陡屋顶常用 |
| 1:2 | 循环: 下半砖 → 上半砖 | 顶面 0.5→1.0, 每 2 格升 1, 很顺 |
| 1:3 | 循环: 下半砖 → 整块 → 上半砖; 或 楼梯 + 1 格整块平段 | 会有一点点顿挫, 远看无妨 |
| 更缓(1:4+) | 楼梯之间插 2~3 格整块平段; 或做成"台地 + 挡土墙"而非连续坡 | 太缓的连续坡反而显得脏 |

**坡度均匀**是关键: 别一段 1:1、一段 1:3 地变。要做变化就变化, 别无意间抖。

## 3. 圆顶 / 球面: 逐层包边

用 `circle-tables.md` §3 的逐层半径 `r_k = round(sqrt(R²−k²))`, 第 k 层在 y=cy+k 画半径 r_k 的实心圆。
光这样层与层之间是垂直的 1 格硬边, 尤其**近顶点半径不怎么变**的部分会顶出平盖子。改善:

- **边缘包一圈半砖**: 每层最外 1 格用**下半砖**代替整块, 落差就从 1 变 0.5, 逐层叠起来就是平滑穹面。
- **边缘包一圈楼梯**: 在下沉的那一侧放楼梯, 高侧朝外, 让两层之间走一个 45° 斜面;
  收口(向内收)时在上一层边缘放**倒楼梯**, 压在整块下沿。
- **顶点收口**: 顶层通常半径会连掉好几格, 用 `upside_down_bit=true` 的倒楼梯和上半砖把帽子收圆,
  别直接一个方块孤零零戳着。
- **能接受就上 0.5 层采样**: 把半径按半格一层算, 整数层放整块、半格层放下半砖, 台阶感直接减半。

**务必先做半径 4~6 的小样**: 画 3~4 层, 退后看轮廓, 确认楼梯朝向和包边方式, 再放大到整个穹顶。

## 4. 用函数铺"高度场"(山丘/波浪屋面)

1. 选一个连续函数, 如 `h(x,z) = round(A·sin(x/λ) + B·cos(z/λ))` 或球面的
   `h = round(sqrt(R² − dx² − dz²))`。
2. 逐列采样, 每列把方块放到高度 h(实心就 `fill` 从基准面到 h)。
3. **平滑**: 相邻列高差保持 ≤1; 函数陡的地方用半砖把 1 格拆成两段。
4. 用**等高线思维**自检: 同一高度 h 的格子应连成闭合、圆滑的环; 层与层之间的环尺寸差 ≤1 就顺。

这是做"自然起伏地面""波浪形雕塑屋面"的通用套路, 比手摆精确得多。

## 5. 拱 / 筒拱 / 穹顶结构

- **拱门**: 两条竖腿 + 一个上半圆(竖直平面上的半圆, 见 `SKILL.md` §3.3)。内圈用倒楼梯/半砖勾边更精致。
- **筒形拱顶(barrel vault)**: 横截面是半圆, 沿长度方向整段复制(`clone` 或逐段 `fill`)。
- **交叉拱(groin vault)**: 两个筒拱相交, 交接处把多余方块用半砖/楼梯替换成斜边。
- 拱的内侧"拱石(keystone)"可以每块转一点角度(用楼梯朝向模拟)来强化曲线感。

## 6. 材质也在"打光"

方块造型再准, 全用同一种方块也会显平。靠**颜色梯度**暗示曲率:

- 曲面用同色系 2~3 档(石 → 安山岩 → 圆石; 或 白混凝土 → 浅灰 → 灰), 高处/迎光面浅、低处/背光面深。
- 曲线边缘用深色方块或台阶"描边", 内圈留浅色, 立刻有立体感。
- 竖向纹理(`pillar_axis="y"` 的原木/石英柱)顺着法线方向铺, 或横向纹理横切, 能强化弧面走向。
- 需要**细曲线**(栏杆、藤蔓、灯带、边界线): 用 `iron_bars` / `fence` / `*_wall` / `chain` / `glass_pane`,
  它们只占 1 格的一部分, 拼出来的圆角比整块自然得多 — 做装饰性圆弧优先考虑。

## 7. 检查清单

- [ ] 相邻层/列高差 ≤1, 没有突然蹦 2 格。
- [ ] 圆顶近顶点的"平盖"用楼梯/倒楼梯/半砖收过口。
- [ ] 半砖是 `bottom` 还是 `top` 没写反(顶面高度差 0.5)。
- [ ] 楼梯朝向实测过(`get_block` 读回确认), 上坡方向一致。
- [ ] 材质有明暗/描边, 不是一坨同色。
- [ ] 先小样后放大, 大工程用 `pin_region` + `ptc` 分批。


## 8. 凸角楼梯 / 凹角半砖(专家补充)

- 曲面边界：**凸角换楼梯，凹角换半砖**；楼梯朝向贴切线，不要全部朝向圆心。
- 过渡带按高差分配：≥1 格/格用整块，0.5~1 格/格用楼梯，≤0.5 格/格用半砖。
- 8~12 格坡常见配比：整块:楼梯:半砖 = 4:4:2 到 5:4:1，半砖收尾贴平地。
- 双层壳：内层按整圆建，外层在转折处用半砖外扩半格，两层错位产生圆润感。
- 楼梯与半砖必须同色系；不同色会把锯齿放大成斑马纹。
- R≥30 曲面按 45° 分 8 段施工，每段单独闭合，重点校验 ±45° 接缝。
