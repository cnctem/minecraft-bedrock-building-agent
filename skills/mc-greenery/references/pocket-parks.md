# 城市口袋公园模块

配套 `SKILL.md` §6。目标是用最少面积做出"可进入、可停留、可识别"的公共绿地。

## 1. 三种尺度

### 9×9 微型花园
- 入口 2~3 格；中央 3×3 花坛/小树池；两侧各 1 组长椅。
- 外围 1 格绿篱，留 2 个对向入口；不能做封闭密室。
- 主景：1 棵小树/花坛/小水钵；不要同时塞大树+水+雕塑。

### 15×15 邻里口袋公园
- 五区压缩为三区：入口广场 5×5、林荫座椅带 5×15、草地/花境 7×7。
- 环路 2 格宽，入口 3 格；主景树在中央偏 1~2 格。
- 座椅 2~3 组，背靠树/矮墙，朝向草地或水景。
- 灯每 6~8 格一盏；至少 1 个无障碍入口。

### 25×25~30×30 综合微型公园
- 六区：入口广场、林荫休憩、草坪、花境/社区花园、活动场、服务角。
- 主环 3 格，次路 2 格；至少 2 个出入口。
- 中央主景 5~9 格；树冠覆盖 30%~50%；灯每 6~10 格。
- 服务角放 `barrel`/`composter`/`cauldron`，不放在主景视线上。

## 2. 五区设计

### 入口广场
- 宽 3~5，硬景 3×3 起；放 1 个标识、2 组花盆/矮灌木。
- 视觉轴线指向主景；不放高篱或大树堵住第一眼。

### 林荫休憩
- 树 2~5 棵成组，间距 4~9；树下座椅成 L 或 U 形。
- 地面可用 `moss_carpet`、`dirt["dirt_type"="coarse"]`、`gravel` 混铺，不要整块地毯。
- 每 2~3 个座椅配 1 盏灯、1 个垃圾桶(`cauldron`/`barrel`)。

### 草坪/花境
- 草坪 7×7 起，边缘 2~3 格花境；留 1~2 格裸土/路径边。
- 草坪上只放 1 个焦点(孤植树/雕塑/野餐点)，避免散布家具。
- 花境 3~7 格一段，颜色主 60、辅 30、叶 10。

### 活动场
- 5×5 起，用不同铺装/矮栏划界；儿童区离水≥3 格，植物无害。
- 可放攀爬架(`fence`/`scaffolding`)、沙坑(`sand`+石缘)、小舞台。
- 至少 2 个出口，避免尽端死角。

### 服务/安静角
- `barrel`、`composter`、`cauldron`、工具架放在次要视线。
- 维修区用 1~2 高绿篱半遮，不完全藏死。
- 安静角 3×3：1 树 + 1 长椅 + 1 灯 + 1 小景即可。

## 3. 动线与铺装

- 入口 3~5，主环 2~3，次路 1~2；不允许断头路，至少形成一个小环。
- 路径转弯 15°~45°，每 5~9 格一个转折；转角放宽 1 格。
- 主路中心 `grass_path`/`stone`，边缘 1 格 `gravel`/`dirt["dirt_type"="coarse"]`，再过渡到草。
- 广场用 2~3 种近似石混铺，每 3~5 格换一块，不做完美棋盘。
- 无障碍：主环坡度 ≤1:2，高差 1 用 `slab`/`stairs`，不连续设台阶。

## 4. 植物配置

- 主景树：1 棵，高 8~18，冠幅 5~7；放在轴线终点或中央偏 1~2。
- 背景树：2~5 棵成组，间距 4~9，高度错 30%。
- 中层：绿篱/灌木 1~3 高，沿边界和座椅背后。
- 地被：草、蕨、花、苔成片，覆盖率 30%~60%，但入口与路径保持清晰。
- 水景：小池 3×3~7×7，岸边缓坡 1~2，至少 1 处观景座椅。

## 5. 家具与设施

| 设施 | 配方 |
|---|---|
| 长椅 | `stairs`座位 + `fence`/`wall`支腿 + `slab`靠背 |
| 桌子 | `fence`×4 + `slab`/`trapdoor`桌面 |
| 灯 | `fence`/`chain` + `lantern`；现代用隐藏 `light_block` |
| 垃圾桶 | `cauldron` 或 `barrel` + `trapdoor`盖 |
| 标识 | `sign`、`frame`、`banner` |
| 花箱 | `mud_bricks`/`stonebrick` 1 圈 + `grass_block`/`moss_block` + 花 |
| 游乐 | `scaffolding`、`fence`、`slime`、`hay_block` 软垫 |
| 水景 | `cauldron` 小水钵；3×3 池 + `stone_slab` 边 |

## 6. 夜间、安全与维护

- 灯每 6~10 格，入口、转角、台阶、座椅、水边加密。
- 路径净宽 ≥2，树枝净高 ≥3；座椅后留 1 格不靠水/陡坡。
- 儿童区远离水、仙人掌、甜浆果丛、火焰、深坑；用矮栏/绿篱围合 1 个入口。
- 视线通透：不要用 3 格高密篱把所有区域围死；至少 30% 区域能从入口看到。
- 公园内设 1~2 个维护点：`barrel`、`composter`、`cauldron`、工具台。

## 7. 交付自检

- [ ] 有主景、次景和明确入口轴线。
- [ ] 乔木/灌木/地被三层齐全，不是草坪+树两件套。
- [ ] 路径形成环，宽度达标，无断头、无堵路。
- [ ] 树冠覆盖率 30%~50%，主路净高 ≥3。
- [ ] 座椅成组，背后有依靠，面向景观。
- [ ] 灯距 ≤10，夜间无连续暗区。
- [ ] 水体封底、缓坡/矮栏到位，儿童区无危险植物。
- [ ] 服务设施可见但不抢主景，维护点齐全。
