# 绿化与景观手册(室内 / 园林 / 城市)

绿化不是"把草和树叶铺满"，而是用 **空间骨架 + 层次 + 焦点 + 动线** 组织植物。
地形改造见 `mc-terrain`，建筑结构见 `mc-architecture`，做旧见 `mc-weathering`，曲线水岸见 `mc-shapes`。

## 0. 六条总原则

1. **先定用途**：通行、休憩、遮阴、观赏、生产、儿童活动；不同用途决定铺装与植物密度。
2. **硬景先行**：先做地形、道路、台地、水岸、挡土墙，再种树；不要先摆树后改地。
3. **三层结构**：乔木(冠层) + 灌木/中层 + 地被/花草。三层齐全才像成熟景观。
4. **焦点与对景**：每个空间 1 个主景(大树/水景/雕塑/花境)，入口或路径尽头能看到它。
5. **成组不成行**：植物按 3、5、7 株成簇，大小混龄；禁止棋盘、等距、同高排列。
6. **可维护可通行**：主路 ≥2 格，树枝离地 ≥3 格，刺状植物不进儿童区，视线不被密篱完全遮挡。

> 自然感口诀：**不等距、不同高、不单层、不直线。** 单株是焦点，成组是背景。

## 1. 工作流

1. `get_player_position` + `get_heightmap` 读场地边界与高差, `get_slice` 看现有建筑与铺装。
2. 画功能图：入口、主路、次路、活动区、安静区、种植区、水景、服务角。
3. 做硬景骨架：地形/台地/挡土墙/道路/广场/水岸，用 `fill` 与 `ptc`。
4. 放大树定冠层和天际线；每 10~20 格 1 棵主树，密林 4~9 格、疏林 10~20 格。
5. 种灌木/绿篱/花境，按 3/5/7 株成组，边界用 1~2 格宽绿篱收口。
6. 铺地被：草、蕨、花、苔藓、落叶；草覆盖率草原 30%~40%，森林 15%~20%。
7. 最后做水、灯、座椅、标识、花盆与维护细节；水最后放。
8. `inspect_region` / `get_slice` 检查树根落地、道路连通、植物不穿墙、光 ≥1。

## 2. 尺度速查

| 项目 | 推荐尺寸 |
|---|---|
| 窗台盆栽 | 1×1，花盆 1 格；成组 3 盆 |
| 室内长花槽 | 3~5 格长、1 格宽，沿窗/隔断 |
| 室内树 | 高 5~9，根/冠半径 2~3；上方至少留 3 格 |
| 绿墙 | 宽 3~5 的倍数，厚 1；每 3~5 格换叶种/色 |
| 阳台/露台 | 深 ≥3；种植槽 1 格，保证 2 格通行 |
| 庭院花园 | 9×9 起；主景 3~5 格，路径 1~2 格 |
| 建筑周边种植带 | 深 1~3；靠墙 1 格低植物，外侧放灌木/树 |
| 树间距 | 密林 4~9；疏林 10~20；行道树 6~10 |
| 绿篱 | 宽 1~2、高 1~3；修剪顶用 `slab`/`stairs` |
| 花境 | 3~7 格一段，3~5 种花/叶混种 |
| 步道 | 主路 2~3；小径 1；口袋公园环路 2~3 |
| 座椅区 | 2~3 格净空，背后/侧后方有遮阴 |
| 水景 | 小池 3×3~7×7；中池 9×9~15×15；岸边缓坡 1~2 |

## 3. 植物层次与配色

- **乔木**：橡/云杉/桦/丛林/金合欢/樱花/红树/棕榈；至少 3 种冠形，树高 ±30%。
- **灌木**：`*_leaves` 团块、杜鹃、浆果丛、竹子、仙人掌(旱区)；高 1~3。
- **地被**：`moss_carpet`、`short_grass`、蕨、花、`pink_petals`、落叶；覆盖要成片但留裸土。
- **垂直**：`vine`、`glow_lichen`、`hanging_roots`、藤蔓架、绿墙。
- **水生**：`seagrass`、`kelp`、`waterlily`、`sugar_cane`、`sea_pickle`、珊瑚。
- 配色取环境色：森林=橡木+深绿，樱花=粉+浅木，沙漠=沙+棕+少量绿，现代=灰白+单色绿，奇幻=青绿+发光。
- 绿色层次至少 2 种明度：深绿做背景，中绿做主体，浅黄绿/花做前景。

## 4. 室内绿化

- 房间 ≥1 盆植物；窗边 3 盆成组；大空间角落放 1 棵室内树。
- 盆栽：`flower_pot`、`barrel`、`decorated_pot`；大型槽用 `mud_bricks`/`stonebrick` 围边。
- 绿墙：木框架 + `moss_block` + `azalea`/`leaves` + `glow_lichen`；每 3~5 格留空，避免整墙同色。
- 悬挂：顶部 `chain`/`fence` 挂 `hanging_roots`、`vine`、`big_dripleaf`、花盆。
- 室内树：树干 `*_log`，冠 2~4 团，根不穿地板；树冠下加 `lantern` 2~3 盏。
- 浴室/厨房用蕨、竹、苔藓；卧室用樱花/白花+浅木；书房用深绿+暖灯。
- 植物不能挡门、挡窗、挡主通道；走廊只放壁挂或窄盆。

## 5. 建筑周边与庭院

- 靠墙 1 格低地被，第二 1~2 格灌木，再外侧 2~4 格乔木；层次从低到高，不遮主窗。
- 入口两侧做对称或平衡的 2 组种植池，路径 2~3 格，门前留 2 格回转区。
- 庭院用主景(树/水/雕塑)+ 次景(花境/座椅)+ 路径环线，至少有 1 处坐下歇脚的空间。
- 阳台/屋顶先确认承重与排水；种植槽高 1~2，底部留排水口或 `cauldron`。
- 建筑与绿地交界用 `gravel`/`dirt["dirt_type"="coarse"]`/石缘收边 1 格，避免裸土直贴墙。
- 临水建筑抬高 ≥2 或木桩架空，岸线种 `sugar_cane`/`waterlily`，不要满铺。

详细植物能力表见 **`references/plants.md`**；庭院、绿墙、建筑周边与风格园林见 **`references/landscape.md`**。

## 6. 城市口袋公园

- 常见规模：9×9 微型花园、15×15 邻里口袋公园、25×25~30×30 综合微型公园。
- 五区：入口广场、林荫休憩、草坪/花境、活动场、服务角；至少 3 区，不必都很大。
- 环路 2~3 格，出入口 3~5 格；不允许只有一条断头路。
- 树冠覆盖 30%~50%，中央留 5~9 格视觉焦点(大树/水景/雕塑/草坪)。
- 每 6~10 格一盏灯；座椅成组，背后有树/墙，面向活动或景观。
- 儿童区远离水、仙人掌和陡坡；用 1~2 格围栏/绿篱分隔，留 1 个入口。

三种布局模块、分区尺寸、家具与安全自检见 **`references/pocket-parks.md`**。

## 7. 工具落地与坑清单

- 大范围先 `pin_region`；地形和铺装用 `fill`，植物与花境用 `ptc` 批量提交 `run_server_command` 的 `setblock`。
- 树必须种在可支撑方块上；花必须长在草/土/苔上；藤蔓要有附着面。
- 坑：满屏草方块、树等距、同种同高、绿篱像墙、灌木单点、路径断头、树穿建筑、花覆盖 100%、水岸直线。
- 坑：室内堆 20 盆小盆栽 → 不如 1 棵室内树 + 3 盆成组 + 1 面绿墙。
- 坑：只看单株不看远景 → 先定树冠轮廓，再补下层植物。
- 坑：植物挡门/挡窗/挡招牌 → 交付前从入口和主路走一遍视线。
- Bedrock ID 与植物状态先 `find_items` + `get_block`；大工程忘 `pin_region` 会导致 `fill` 失败。
