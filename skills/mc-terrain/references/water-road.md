# 水景 · 道路 · 桥梁 · 农田 · 与建筑衔接

配套 `SKILL.md` §4/§6。ID 以 `find_items` 为准: `water`、`grass_path`(土径)、`farmland`、
`gravel`、`cobblestone`、`stonebrick`、`*_fence`、`iron_bars`、`chain`、`sugar_cane`、`waterlily`。

---

## 1. 水景

**水的基本行为**(基岩版): 水源(`water`)水平会向四周流最多 7 格; **下落中的水不横向扩散**, 落地后才扩散。
所以: 静水靠"围合+注满水源", 瀑布靠"1 格宽下落", 落地要接水池。

- **静水湖/池**: 用实心块把盆地**围死**(不能有缺口), 再 `fill <x1> <水面y> <z1> <x2> <水面y> <z2> water`。
  下层可以是空气, 水面那层放水源即可保持; 或整块填满更保险。
- **河流**: 先沿曲线挖**河床**(宽 2~4、深 2~3, 底铺 `gravel`/`sand`/`clay`), 再在**水面层**沿河道放水源
  (`fill` 一条曲线)。河要有**流向感**: 上游高、下游低, 每段落差用 1 格小瀑布连。
- **瀑布**: 崖顶做一个**缺口 + 水源**, 水从缺口**1 格宽**落下 → 不扩散。落地处做**水潭**承接; 想要水花就
  在水潭底放 `moss_block`/`seagrass`。大瀑布: 多层阶梯落下, 中间加岩石分水。
- **涌泉 / 溪流**: 石缝里的水源 + 一条蜿蜒小溪, 用 `cobblestone`/`mossy_cobblestone` 镶边。
- **水下地形**: 湖/海底铺沙泥起伏, 放 `seagrass`/`kelp` 海草、`sea_pickle`、`prismarine` 遗迹、珊瑚。
- **排水防漏**: 开工前想好水会流到哪; 池壁留 1 格厚以上, 或外侧再包一层防渗。
- 想"活水有声音/气泡": `magma` + 水产生气泡柱(上升)或 `soul_sand` + 水(上升气泡电梯)。

## 2. 道路与小径

- **走曲线**: 两点之间别连直线。手工做法: 先定 3~5 个途经点, 点间用**大弧或折线**, 再在边缘随机加/删 1 格。
- **宽度变化**: 主路 2~3 格、小径 1 格; 途中宽窄交替, 岔口加宽成小广场。
- **材质混合**: 一条路上混 `grass_path` + `gravel` + `cobblestone` + 偶发 `stonebrick`/`andesite`,
  别一种铺到底; 边缘**毛边**(掺草/土/碎砖)。
- **坡道**: 上下坡用 `*_stairs`/`*_slab` 接, 别让路突然断一层。
- **路旁**: 路灯(`*_fence` + `lantern`)、界石、灌木、花、矮墙; 但**成组且不规律**。
- **石板广场/庭院**: 大面铺装用**网格 + 杂色**(每隔几格换个近似石色), 边缘做花坛收边。

## 3. 桥梁

| 类型 | 结构 | 要点 |
|---|---|---|
| 平板桥 | 桥面 + 桥墩 | 最简单; 墩落在河床/地面 |
| 拱桥 | 拱券(见 `mc-architecture` 拱券) | 跨度大, 拱脚落在两岸石基 |
| 吊桥 | 塔 + `chain` 悬索 + 桥面 | 链做缆, 桥板略下垂 |
| 廊桥 | 桥面 + 柱 + 顶 | 有屋顶, 可当"过河街道" |

- **桥墩必须落地**(河床/岸基), 别悬空; 入水墩加 `mossy_cobblestone`/藤蔓做水位线。
- **桥面微拱**更真实(中间略高 1 格); 栏杆用 `<木>_fence`/`<木>_wall`/`iron_bars`。
- 桥头接**台阶/引道**, 与地形路顺接。

## 4. 农田 / 梯田 / 牧场

- **农田**: `farmland` 条垄 + **水渠**(每 4~8 格一条水沟, 或垄间穿插水格), 种 `wheat`/`carrot`/`potato`/
  `beetroot`。垄向一致, 田埂用土/石小路。加稻草人(`*_fence`+`hay_block`+南瓜头)。
- **梯田**: 顺**等高线**一层层做平, 每层外侧**挡土墙**(石/木), 层间台阶/水渠; 田块略错落。
- **果园**: 成排但不完全等距的果树(`vegetation.md` 树型); 篱笆围合。
- **牧场**: `<木>_fence` 围栏 + 草场 + 水槽/干草堆(`hay_block`); 栏门用 `fence_gate`。

## 5. 地形与建筑的衔接(最容易翻车的地方)

- **台基找平**: 建筑必须坐在一个**平整台基**上(见 `mc-architecture` 台基), 台基外扩 1 格。
- **挡土墙 / 护坡**: 建筑临坡一侧, 用 `stonebrick`/`cobblestone` 砌**挡土墙**(可加**扶壁**),
  墙后填土; 别让裸土直接堆在墙边。
- **开挖 / 回填**: 山体里建房子就**挖进去**(半地下/窑洞), 或把坡**削成台地**再建。
- **台阶与坡道**: 建筑入口与地形的高差, 用台阶(`*_stairs`)+ 台地 + 引道顺接。
- **庭院**: 建筑与地形之间做**铺装庭院** —— 石板 + 花坛 + 水池 + 树 + 灯; 边界用矮墙/篱笆/绿篱。
- **嵌山**: 背靠山体的建筑可做**错层**(顺着坡分层), 屋顶与山脊呼应; 或直接做成**崖居/洞穴宅**。
- **收边**: 建筑周围的裸地最后都要**铺草/碎石/花坛**, 别留突兀的方块切口。
- **视线**: 从主入口往外看, 应该有景(水池/庭院/远山), 而不是一堵土墙。

## 6. 落地提示

- 大范围地形/水使用 `pin_region` 覆盖, 再 `ptc` 批量 `fill`; 水务必**最后注**, 先取样机试一小块看流不流。
- 注水前用 `inspect_region`(filter=池底材质) 检查池底/河床有没有洞(mismatch 里的 air 就补, 否则漏水)。
- 改完地形用 `get_heightmap` 抽查岸边/水线高度是否一致。
