# 植被与自定义树木

配套 `SKILL.md` §5。**别直接种树苗等自然生长**(慢、随机、东倒西歪), 用 `setblock` 手搭。
树干 `<木>_log`, 树冠 `<木>_leaves`(玩家放置的树叶不会枯萎); 有条件的加 `<木>_log` 树桩/枝桠与 `vine` 垂藤。

坐标: 树干基座在 `(x, y, z)`。树冠"去角"= 5×5/3×3 里去掉四角, 更圆润。

---

## 1. 五种基础树型

### 橡树 / 白桦(阔叶球冠)
```
fill x y z  x y+4 z oak_log                 # 干 5 高(白桦 6~7)
# 冠: 三层球(minus 四角)
#   y+3: 5×5 去四角      (半径 2)
#   y+4: 5×5 去四角      (半径 2)  —— 橡树可厚一点
#   y+5: 3×3 去四角 + 顶 1 格
fill x-2 y+3 z-2  x+2 y+3 z+2 oak_leaves    # 再去掉四角
```
> 冠高 2~3 层就够; 枝上偶尔伸 1 格 `oak_log` 顶出冠外, 更自然。

### 云杉 / 松(锥形冠)
```
fill x y z  x y+9 z spruce_log              # 直干 8~12 高
# 从 y+3 起, 自下而上每 1~2 层一个"圆盘", 半径: 2,2,1,2,1,1,0,0
#   半径 2 = 5×5 去四角; 半径 1 = 3×3 去四角; 半径 0 = 单格
# 顶端收成一个尖
```
> 分层间距: 密(每层)显茂密, 隔层显瘦高。冷杉/松树都这样。

### 丛林木(高 + 宽冠)
干 8~15, 树冠半径 3~4(7×7 去角), 顶层 3×3; 干上绕 1~3 条 `vine` 垂到地面; 可加 2~3 根横向枝。

### 深色橡树(粗干大冠)
干 2×2、高 6~8(`fill` 四边形), 树冠半径 3~4、厚 3~4 层, 冠下缘参差。

### 枯树(无叶)
干 3~5 高, 从干中部伸 2~4 根**斜向枝**(用 `*_log` 逐格偏移), 枝端收 1 格短截; 整体倾斜一点。

## 2. 特殊树型

### 棕榈(弯曲干 + 放射叶)
```
setblock x   y   z jungle_log
setblock x   y+1 z jungle_log
setblock x+1 y+2 z jungle_log        # 逐格朝 1 个方向倾斜
setblock x+1 y+3 z jungle_log
setblock x+2 y+4 z jungle_log
# 顶端 (x+2,y+5,z): 4~6 片"棕榈叶"朝四周放射, 每片末端下垂 1 格
#   用 jungle_leaves 或 oak_leaves, 每片长 3~4 格
```
### 金合欢(伞状)
干 3~5 后**斜向**再走 2~4 格, 顶端铺一个**扁平**的伞冠(5×5~7×7, 只 1~2 层, 底面平、边缘散)。

### 樱花(粉冠、弯曲)
干 4~6 略弯, 冠用 `cherry_leaves`(粉色), 半径 2, 层厚 2~3, 冠下缘碎; 地面撒 `pink_petals`。

### 巨树(地标)
```
fill x y z  x+2 y+15 z+2 <木>_log          # 3×3 主干 15~20 高
# 板根: 基部四周斜向下伸出 2~4 格 *__log
# 大冠: 半径 4~6 的半球(见 mc-shapes), 厚 4~6 层
# 枝: 干上 3~5 处分叉, 各撑一个子冠
```
### 红树(气生根)
干 4~6, 基部八方向斜向下伸 `mangrove_log` 作**支柱根**入水/入地; 冠半径 2~3。

## 3. 灌木 / 花草 / 下层植被

- **灌木**: 3×3 以内的 `*_leaves` 一小团(可加 `*_log` 短桩), 高 1~2。
- **花丛**: `short_grass`/`tall_grass`/`fern` 铺地, 混 `poppy`/`dandelion`/`blue_orchid`/`allium`/`red_tulip`
  /`sunflower`/`lilac`/`rose_bush`/`peony`; 成簇, 别单点均匀撒。
- **蘑菇**: `brown_mushroom`/`red_mushroom` 在阴湿处; 巨型蘑菇用茎 + 伞盖方块搭。
- **竹林**: `bamboo` 丛生(2~4 根一簇), 高 8~12; 竹笋用矮竹。
- **藤蔓 / 垂吊**: `vine` 从冠/崖垂下; `glow_lichen`/`hanging_roots`/`moss_carpet` 做潮湿地被。
- **落叶堆**: 用 `*_leaves` 单层平铺当地面落叶(透明, 不挡路)。
- **睡莲 / 芦苇**: `waterlily` 浮水面, `sugar_cane` 沿水岸(必须挨着水/沙土)。

## 4. 分布原则(别摆棋盘)

1. **成簇**: 树 3~6 棵一簇, 簇间留空地/林窗。
2. **混龄**: 大树、小树、幼苗穿插。
3. **疏密不均**: 有的密到接冠, 有的稀疏。
4. **成对/三角**: 相邻树位置别排成正方格, 轻微错位。
5. **下层跟着树走**: 树荫下草少、藤蔓/蘑菇多; 林窗里花草多。
6. **边缘渐疏**: 树林边缘树木逐渐变稀、变小。

## 5. 群系植被搭配速查

| 群系 | 主树 | 地被 | 点缀 |
|---|---|---|---|
| 平原 / 草甸 | 橡树、少量桦树 | 草 + 各色花 | 蜂巢、小水池 |
| 森林 | 橡/桦/深色橡混交 | 蕨、蘑菇 | 倒木、藤蔓 |
| 针叶林 / 山地 | 云杉、松 | 雪层、苔藓 | 巨石、雪 |
| 丛林 | 丛林树、竹 | 蕨、大型垂滴叶 | 藤蔓、鹦鹉栖木 |
| 稀树草原 | 金合欢 | 黄绿草 | 巨石、秃枝 |
| 沙漠 | 无(或仙人掌) | 干枯灌木 | 砂岩露头、绿洲 |
| 沼泽 | 红树/枯树 | 睡莲、苔藓 | 沼气、倒木 |
| 樱花林 / 温带 | 樱花 | 粉花瓣、花 | 小径、石灯 |
| 雪原 | 云杉(覆雪) | 雪层 | 冰湖、冰柱 |
| 热带海岛 | 棕榈 | 沙、海草 | 礁石、潮池 |
| 樱花/精灵/奇幻 | 樱花 + 巨树 | 发光地衣、苔藓 | 萤石、藤桥、发光菌 |
