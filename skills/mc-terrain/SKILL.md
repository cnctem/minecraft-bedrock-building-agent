# 地形与景观手册(自然感 / 造景)

地形不是随机堆方块，而是 **轮廓优先 → 大块面 → 材质分区 → 微地形 → 植被 → 水体 → 做旧**。
曲线用 `mc-build`，建筑结构用 `mc-architecture`，内饰用 `mc-interior`。

## 0. 五条铁律

1. **不用直线**：山脊、河岸、路、湖岸都弯，边界每 3~8 格随机凸凹 1~2 格。
2. **不用等距**：树、石、花、峰距都不均匀；单座山用 1 主峰 + 2~4 山肩，山群用 3~5 奇峰。
3. **多层过渡**：草 → 粗土/土 → 石至少三层；两种材质交界留 3~7 格混合带。
4. **坡度有缓急**：水平:垂直 ≤3:1 为缓坡，1.5:1~1:1 为陡坡，超过 1:1 改崖壁逻辑。
5. **边缘破碎**：留孤石、断枝、缺口、碎石和明暗斑块；齐整边最假。

> 任何装饰都要能回答"为什么长在这里"：水边=苔/苇，背阴=苔/蕨，人为=grass_path/砂土。

## 0.5 生成器优先(确定性生成器)

本手册给了四个**确定性**生成器（同坐标同 seed 永远同结果，可分块施工、可重跑）：

| 函数 | 作用 | 参数 |
|---|---|---|
| `terrain(cu, v, cw, size, profile)` | 起伏地面 | profile: hills（默认）/ mountains / plateau / basin / islands（后两者低处自动灌水） |
| `vegetation(cu, v, cw, size, biome)` | 乔木 + 地被 | biome: forest（默认）/ plains / taiga / jungle / savanna / swamp / desert / birch |
| `ruins(cu, v, cw, size, age)` | 遗迹院落 | age 0~100（0 = 基本完好，100 = 只剩墙根残基） |
| `road(u1,v1,w1, u2,v2,w2, width, kind)` | 自然弯曲道路 | width 默认 5；kind: dirt / stone / cobble / mud / highway |

推荐串法：`terrain` 出起伏 → `ruins` 放废墟 → `vegetation` 种树 → `road` 从路口通到废墟
（本手册的“被森林吞没的古代遗迹”）。完整说明见 **`references/domain-generators.md`**。

它们只铺“地表 + 下两层”与自然物分布，**不做大尺度体量**：山形、谷地、湖岸的骨架仍按 §2
的高度场分层做；生成器负责表面材质、植被密度、遗迹风化与道路走向这些“自然感”部分。

## 1. 工作流

1. `get_heightmap` 默认摘要看现有高度(可先用 `find_blocks` 找水面 y)，先定最低水面、谷底和建筑基址；需要逐列塑形时再把局部缩到 ≤32×32 用 `detail="heights"`，需要岸线/顶面分布时才用 `full`。
2. 用灰度思维定 3~5 个高度层：谷底/坡脚/山腰/峰顶/天际线；剪影至少读出高-中-低三个节奏。
3. 粗造型：大块 `fill` 堆石/土，允许此时难看；先大范围，再做局部。
4. 修坡度：缓坡半砖/整块，陡坡楼梯，>1:1 转崖壁；每层轮廓内缩 1~3 格。
5. 材质分区：按高度/坡度铺地表；至少一种石头贯穿山脚到山顶，避免"叠了几层"。
6. 微地形：±1~2 格起伏、裂缝、碎石带、平台、凹龛。
7. 植被：树 → 灌木 → 草花 → 苔藓/藤蔓；水体最后放，避免提前冲毁工地。
8. 做旧：同类材质 5%~15% 互掺，特殊装饰在任意 10×10 内 ≤15%。
9. `pin_region` 覆盖全范围，`ptc` 批量提交 `fill/setblock`；完事用 `inspect_region`(filter=目标) 与 `get_heightmap` 验收，先看摘要，只对需要逐列核对的局部请求完整网格。

## 2. 高度场四种做法

- **控制点插值**：每 4~8 格定高度点，相邻高差 ≤1~2，再做双轴插值。
- **分层等高线**：每升高 1~2 格用不规则闭合曲线圈范围，层层缩小；层厚交替、偏移 ±2。
- **正弦叠加**：`h=round(A·sin(x/k)+B·cos(z/k)+C·sin((x+z)/k2))`，2~3 个波长叠加。
- **手工扰动**：规则形体完成后按固定序列边缘加减 1~2 格，禁止真随机撒胡椒面。

高度参考：丘陵 5~12，山 10~30，悬崖 8~20，台地每层 4~8。

## 3. 山体与崖壁

- 山体层厚 4~8，上层底面比下层内缩 2~4，偏移 ±2；山腰留 1~2 个宽 ≥7 的平台。
- 山脚到山顶按加权材质换带：草土带 → 岩土混合带 → 山腰岩壁带 → 高山裸岩带 → 雪顶；石头至少贯穿 5%。
- 雪线/林线用渐变，不做硬直边：雪块从 30% 过渡到 70%。
- 崖壁：岩层单层 3~7 格、同崖 3~6 层，层间水平错动 2~6 格；严禁等宽水平直条纹。
- 崖面每 4~8 格进退 1~2 格；裂缝宽 1、长 6~15，每 15~20 格崖宽至少 1 条。
- 崖脚碎石带宽 ≈崖高 1/4~1/3，坡度 ≤25°，大块靠崖脚、碎屑靠外。
- 五套配色、加权配方与嵌山流程见 `references/expert-rules.md`；基础造法见 `references/landforms.md`。

## 4. 水与道路

| 要素 | 关键尺寸 |
|---|---|
| 池塘 | 宽 5~15、深 2~4；湖宽 20~60、深 4~8，湖心最深 |
| 河 | 支流 3~4、普通河 5~9、通航河 10~15；深 2~4 |
| 蛇曲 | 弯间距 = 河宽 ×4~7；凹岸冲刷加深，凸岸浅滩堆积 |
| 瀑布 | 崖高 ≥6；口宽 2~5(3 最自然)；瀑口岩石外挑 1~2 格 |
| 湖底 | 浅水 `sand` → `gravel`/`clay`，冷地 `podzol + gravel`，禁止直接草底 |
| 道路 | 小径 2~3、村道 4~6、石道 5~7、山路 2~3 之字形 |
| 桥 | 小沟跨 4~7 木桥；石桥跨 8~15，拱高 = 跨 ×1/5~1/4 |

- 河先在岸线放醒目方块定中线，再开挖；瀑布必须 1 格宽下落才不横向扩散，落点接水潭。
- 路中心压实、边缘松散；中心 `grass_path/gravel`，向外 1~2 格混 `dirt["dirt_type"="coarse"]` 再回草。
- 四级路面配方、两岸做法、桥类型见 `references/expert-rules.md` 与 `references/water-road.md`。

## 5. 树木与植被

- 自定义树 = 树干 + 2~5 根 40%~70% 高处出的枝 + 3~6 团半径 1.5~3 的叶球；每球挖 2~4 个缺口，底层留 1~2 格垂叶。
- 同片林树高 ±30%，至少 3 种冠形；密林间距 4~9，疏林 10~20，禁止网格对齐。
- 树干根肩外扩，大树做 2~4 条外露根；樱花、金合欢、棕榈、红树、枯树各有专属轮廓。
- 草原草覆盖 30%~40%，森林草 15%~20% + 蕨 15%，针叶林草 5% + 蕨 20%；花每 6~10 格 1 株。
- 苔藓阴面 15%~30%、水边 40%+，3~7 格成团；藤蔓每 4~6 格檐缘 1 根，垂 2~5 格。
- 15 种树参数表、树冠变体、下层密度见 `references/expert-rules.md`；基础树型见 `references/vegetation.md`。

## 6. 与建筑 / 农田衔接

- 建筑地坪与自然地面高差 2~4：做挡土墙 + 压顶；>4 改台地，每层用 1:2 坡道或 3~5 级台阶。
- 台地边缘收 1~2 格石缘，石缘下挂藤蔓；庭院铺装 + 花坛 + 水池 + 树 + 灯。
- 嵌山：先整平建筑顶面 → 做主体 → 从侧壁向外长崖壁包住背/两翼 → 接缝撒 gravel/moss。
- 半地下：屋顶覆土 ≥2 格，坡向一侧，屋脊高出地面 1~2 格，边缘垂藤。
- 烟囱/塔楼轮廓不要与山体平行；交角取 30°~60°。主入口视线要有景，不能正对土墙。

## 7. 工具落地

1. `get_player_position` + `get_heightmap` 量范围；2. `pin_region` 覆盖施工区；
3. 大块 `fill` 做骨架；4. `ptc` 批量提交 `run_server_command` 的 `setblock/fill`，做材质与微地形；
5. 先取样机注一小块水，确认不漏再全面注水；6. `inspect_region` 检查岸线、水线、空洞与树根落地。

## 8. 坑清单

- 方方正正一大块、岸线笔直、等高线等宽 → 一眼人工；破形、蛇曲、层厚交替。
- 草方块直接接石头、雪线硬切、岩层水平直条纹 → 至少 3 层、3~7 格混合带、层内互掺。
- 山形馒头化、所有峰同高、坡度全程一样 → 奇峰 + 平台 + 陡坎 + 裂缝。
- 湖底/河底直接铺草 → 用 sand/dirt/clay/gravel 的深度序列。
- 瀑布宽面平挂、河凭空开始 → 瀑口内凹 + 岩唇 + 明确源头。
- 树等距、同高、完美球形 → ±30% 高度、3 种冠形、每球挖缺口。
- 装饰过载、苔藓单点、藤蔓满墙 → 成簇、10×10 内特殊块 ≤15%。
- 地形与建筑生硬相接 → 挡土墙/台地/嵌山之一，不用裸土贴墙。
- 先注水后改地形 → 容易淹工地/漏水；铁律是**水最后放**。
- 大工程忘 `pin_region`，ID 凭记忆猜 → `find_items` + `get_block` 实测。
