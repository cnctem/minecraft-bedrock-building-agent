# 会话与上下文

所有普通、创造和一次性任务共用当前 `api_key/api_base/model`。
运行模式控制思考强度、输出预算和工具权限，见[运行模式](modes.md)。

## 生命周期与稳定前缀

- 玩家数从 0 变为 1 时，空闲状态下完整初始化会话；正在执行的任务继续使用原会话。
- 玩家全部离服时会话不结束，任务可以继续；下次进服或“清空”才建立新会话。
- “清空”仅在空闲时生效，旧会话先落盘。执行任务、待处理队列或智能压缩都会阻止清空。
- system prompt 在实例内按 `agent_name` 固定，记忆、技能目录、模式和对话状态以系统注记追加。
- 平时只追加消息，不滑动裁剪或重排已有前缀。任务中的新消息在工具往返闭合后进入上下文。

## 工具配对与 DeepSeek 扩展

每条 `assistant(tool_calls)` 后必须紧跟全部对应的 `tool` 响应，再加入模式注记、玩家插话或工具附图。
强制停止也要补齐未执行工具的响应。请求前清理孤儿结果和无法配对的调用，避免接口拒绝整个会话。

带函数调用的 assistant 原样保留 `reasoning_content`；恢复缺字段的记录时补空字符串。
DeepSeek 原生联网的 `server_tool_calls` 保存在消息中，并在后续请求原样回传。
工具消息只放文本；渲染图通过带系统说明的额外 user 消息附加，玩家直链图片附在原玩家消息里。

## 普通压缩

完全匹配“压缩”且空闲时，保留玩家文字和通过 `send_chat_message` 实际说出口的话。
ptc 内的发言会被提取，其余工具、思考、普通正文与旧系统注记移除。
压缩后重建记忆、技能目录、当前模式和压缩说明；最后一次建造程序原样附上。
旧会话保存为 `compact-*.jsonl`，不作为“恢复会话”的候选。

## 智能压缩与预算

“智能压缩”先调用 DeepSeek 生成工作摘要，记录目标、坐标、尺寸、建造进度、失败和待办，
再附上最近对话及最后一次建造程序。摘要失败或被停止时原上下文保持完整。
后台摘要期间消息排队，完成后唤醒 worker。

输入预算为 `context_window_tokens - 本轮输出额度 - context_safety_tokens`，最低 4096。
默认用到输入预算的 95% 时自动智能压缩；自动摘要失败后本会话不重复尝试，仍可手动触发。
超过预算时尝试普通压缩，仍无法容纳才完整初始化。
达到配置窗口 70%、80%、90% 时各提醒一次，压缩后复位。

## 长期记忆

只有玩家明确要求记住、修改或忘记时才调用 `update_memory`。
记忆文件只保存当前值，通过同目录临时文件和原子替换更新；失败时保留原值并清理临时文件。
更新后追加系统注记，不重写固定前缀。

## 落盘与恢复

含实际 user/assistant 对话的会话才写入 `logs/sessions/session-*.jsonl`。
首行 `_meta` 记录会话编号、发言名称与开始时间，不是模型消息。
“恢复会话”选择最近一份含对话的文件，恢复模式与对话状态，并追加“历史已经执行，不要重跑”的注记。
技能目录有变化时也仅在末尾补注记。

```bash
python3 bot.py --resume logs/sessions/session-....jsonl
```

启动辅助可使用 `AGENT_RESTORE`，详见[运行文档](operations.md)。
恢复使用当前 DeepSeek 配置和 `agent_name`，历史记录中的名称只用于展示原有发言。

## 一次性任务

`1 ...` 使用独立上下文、取消信号与日志目录；主会话不会看到请求和执行过程。
并发数由 `oneshot_max_concurrent` 限制，权限由一次性白名单限制，不能进入创造模式。
任务在同一次请求中完成并给出一条最终回复；含糊请求说明缺少什么后结束。
`1 强制停止` 中止所有一次性任务；普通“强制停止”只作用于主任务。

静默前缀 `0 ...` 不进入任何上下文，不唤醒 worker，也不改变对话状态。
